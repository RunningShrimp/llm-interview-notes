## 算法地图（按套路分组）

面试不考"原题"考"套路"。把 17 组按底层套路再聚类，刷完一类就能 hold 住一类追问：

```text
                  ┌── 01 哈希：O(1) 查询 / 计数
                  │
                  ├── 02 双指针 ──┐
                  │              ├── 03 滑动窗口：连续区间
                  │              │
                  │              └── 04 子串：前缀和 + 哈希表
                  │
   数组/序列 ─────┼── 05 普通数组：原地操作 / 旋转
                  ├── 06 矩阵：坐标变换 / 方向数组
                  │
                  ├── 11 二分查找：单调 / 断崖
                  └── 12 栈：嵌套 + 单调

   链表/树/图 ────┼── 07 链表：双指针 / 反转 / 哨兵
                  ├── 08 二叉树：BFS / DFS / 构造
                  └── 09 图论：BFS / UnionFind / Trie

   暴力穷举 ──────┼── 10 回溯：决策树 + 剪枝
                  └── 17 多维动态规划：网格 / 区间 / 双串

   局部最优 ──────┼── 13 堆：TopK / 中位数 / 多路归并
                  └── 14 贪心：区间 / 跳跃 / 排序反证

   DP 大系 ───────┼── 16 动态规划：一维状态
                  │
                  ├── 12 栈（LC739 单调栈可纳入 DP 思维）
                  │
                  └── 15 技巧：位运算 / 前缀异或 / 抽屉
```

**面试官最爱问的几类套路**（频次从高到低）：

1. **双指针 + 滑动窗口**（02 + 03 + 04，9 题）：连续区间、和/计数问题的一半解法。
2. **动态规划**（16 + 17，15 题）：一维 + 二维构成大半个算法面。
3. **二叉树 DFS / BFS**（08，15 题）：递归框架掌握就稳拿。
4. **回溯**（10，8 题）：组合/排列/构造型穷举的统一模板。
5. **链表**（07，14 题）：高频快指针 + 哨兵，反转是必背模板。

## 刷题顺序建议

### 第一阶段：基础盘（建议 1 周，~25 题）

```text
01 哈希(3) → 02 双指针(4) → 03 滑动窗口(2) → 05 普通数组(5) → 12 栈(4) → 14 贪心(3) → 13 堆(3)
```

目标：把"数组 + 哈希 + 双指针"焊成肌肉记忆，能 10 分钟内口述思路 + 写出 Go 代码。

### 第二阶段：套路升级（建议 2 周，~40 题）

```text
04 子串(3) → 06 矩阵(4) → 11 二分查找(6) → 15 技巧(6) → 07 链表(14) → 09 图论(6) → 10 回溯(8)
```

目标：每类套路至少吃透 5 题以上，能在变形题里识别"哦这是 XX 套路换皮"。

### 第三阶段：DP 大系（建议 2 周，~25 题）

```text
16 动态规划(10) → 17 多维动态规划(5) → 08 二叉树(15)  ← DP 多和二叉树交织练
```

目标：DP 五步法焊死（状态定义 → 转移方程 → 初始化 → 遍历顺序 → 返回值），二叉树递归框架变成下意识。

### 第四阶段：差缺补漏（建议 1 周）

回头补"卡得最久的 10 题"——每个人的弱点不同，但常见痛点：

- 二分查找的**边界条件**（LC34 找左右边界、LC153 旋转数组最小值）
- 单调栈（LC739 每日温度 → 推进到 LC42 接雨水、LC84 柱状图）
- 编辑距离 / LCS（LC72 / LC1143）的"边界初始化 + 三方向转移"
- N 皇后（LC51）的对角线公式 `row+col` / `row−col+n`

### 代码风格

- 每题一段 **完整可编译 Go 代码**（`package main` + import + LeetCode 签名 + 关键行注释 + main 双断言）。

### 🎤 口述模板

每题末尾的"口述模板"是**面试白板口述时的小抄**：先把状态/转移/边界用一句话说清楚，再讲复杂度，最后**主动展开一个常见追问**（如"如果换成倒序遍历会怎样""如果输入换成流式数据怎么改"）。

面试准备 = **每题都能口述 60 秒讲清楚**，比"代码默写一字不差"重要十倍。

## 复盘公式：每题必过的三道关

刷完一道题，**自查三件事**——做不到就重新看：

1. **能不能 60 秒说清思路？** 状态 / 边界 / 转移三件事各一句，不磕绊。
2. **能不能 5 分钟写出来？** 关键行注释能复述对应行号——说明真的懂而不是抄。
3. **能不能 30 秒改对追问？** 常见追问（变体、改条件、改约束）能口述修改点。

100 题 × 三道关 = 300 次刻意练习，比刷 1000 题零散重复有效得多。
