# 03 · 滑动窗口：双指针的"区间版"

> 热题 100 · 滑动窗口组 · 2 题。滑动窗口就是双指针的特化：**右指针贪心扩张、左指针按需收缩，维护一个"始终合法（或努力变合法）的区间**"。它适用的前提只有一个：窗口的合法性随左右端移动**单调变化**——右扩只会更"满"，左缩只会更"空"。有这个单调性，每个元素进出窗口各一次，O(n)。

## 本组题目总览

| 题号 | 题目 | 核心考点 | 难度 |
|------|------|----------|------|
| LC438 | 找到字符串中所有字母异位词 | 定长窗口 + 计数数组 | 中等 |
| LC3 | 无重复字符的最长子串 | 不定长窗口 + 哈希记下标 | 中等 |

先建立整体感，两种窗口的分野：

| 特征 | 定长窗口 | 不定长窗口 |
|---|---|---|
| 窗口大小 | 题目直接给（= len(p)） | 是要求解的目标（最长/最短） |
| 移动方式 | 进一个、出一个，齐步走 | 右端贪心扩，左端违规才缩 |
| 判定时机 | 每次滑动后判定 | 收缩完成后结算 |
| 本组例题 | LC438 | LC3 |

## LC438 找到字符串中所有字母异位词（中等）

### 题干简述

LeetCode 438 · Find All Anagrams in a String · 中等。给定字符串 `s` 和非空串 `p`，找到 `s` 中所有是 `p` 的**异位词**的子串，返回这些子串的**起始索引**。子串长度必须等于 `len(p)`，不含重排以外的字符。

示例：`s = "cbaebabacd", p = "abc"` → `[0, 6]`（"cba" 和 "bac"）。

### 解题思路：定长窗口 + 计数数组

突破口是"异位词子串长度必然等于 len(p)"——**窗口宽度直接被题目锁定**，这是定长窗口的招牌特征。

暴力做法：对 s 的每个起点截出长度为 len(p) 的子串，排序后和 p 比，O(n · k log k)，太慢。问题出在每滑一格都"推倒重来"。

定长窗口的增量思维：窗口每右滑一格，**只发生两件事**——右端进一个字符、左端出一个字符。维护一个 26 长度的窗口计数数组，这两件事都是 O(1) 的加减；再和 p 的计数数组比较即可。

```
s = "cbaebabacd", p = "abc"，窗口宽度固定 3

 c  b  a | e  b  a  b  a  c  d
 ├───────┤                     窗口 "cba"：计数 == p ✔ 记起点 0
    ├───────┤                  "bae" ✘
       ├───────┤               "aeb" ✘
          ...中间全部 ✘...
                   ├───────┤   "bac" ✔ 记起点 6

每滑一格只做两个 O(1) 动作：
  进：win[s[right]]++
  出：win[s[right - 3]]--
然后整表比较 win == need（26 次，常数级）
```

Go 的福利：`[26]int` 数组**可直接 `==` 比较**，不用手写 26 次循环。

### 代码

```go
package main

import "fmt"

func findAnagrams(s string, p string) []int {
	res := []int{}
	m, n := len(s), len(p)
	if m < n {
		return res // 边界：s 比 p 还短
	}
	var need [26]int // p 的字母计数（目标指纹）
	var win [26]int  // 当前窗口的字母计数
	for i := 0; i < n; i++ {
		need[p[i]-'a']++
		win[s[i]-'a']++ // 先装满第一个窗口
	}
	if win == need { // [26]int 可直接比较
		res = append(res, 0) // 第一个窗口也要判一次
	}
	for right := n; right < m; right++ {
		win[s[right]-'a']++   // 新字符进窗
		win[s[right-n]-'a']-- // 左端字符出窗
		if win == need {
			res = append(res, right-n+1) // 新窗口的起点
		}
	}
	return res
}

func main() {
	fmt.Println(findAnagrams("cbaebabacd", "abc")) // [0 6]
	fmt.Println(findAnagrams("abab", "ab"))        // [0 1 2]
}
```

### 复杂度

| 解法 | 时间 | 空间 |
|------|------|------|
| 每个起点截串排序比较 | O(n · k log k) | O(n) |
| 定长窗口 + 计数数组 | O(n · 26) = O(n) | O(26) = O(1) |

想再抠一点：可以维护一个"与目标不匹配的字符个数"变量 diff，进/出窗时增量更新，diff==0 即命中，把每步的 26 次比较降到 O(1)。但 26 本来就是常数，复杂度量级不变——面试提一句"还可以这么优化"即可加分。

### 易错点

1. 起点 = `right - n + 1`（新窗口左端），别写成 `right - n` 或 `right`。
2. **第一个窗口**（下标 0~n-1）要在进入循环前单独判一次，最常见的漏判。
3. `len(s) < len(p)` 的边界要先返回空切片。
4. 用 `[26]int` 的前提是**只含小写字母**；有 Unicode 就得退回 `map[rune]int` + 手写比较。

### 🎤 口述模板

"这是定长窗口：窗口宽度就是 p 的长度。维护两个 26 长度的计数数组——p 的指纹和当前窗口的计数，每滑一格进一个字符、出一个字符，做 O(1) 的增量更新，然后比较两个数组是否相等。比较是 26 次常数操作；想更抠可以维护差异计数变量做到每步 O(1)，但量级一样，整体都是 O(n)。"

## LC3 无重复字符的最长子串（中等）

### 题干简述

LeetCode 3 · Longest Substring Without Repeating Characters · 中等。给定字符串 `s`，求**不含重复字符**的**最长子串**长度。

示例：`"abcabcbb"` → `3`（"abc"）；`"bbbbb"` → `1`；`"pwwkew"` → `3`（"wke"，注意是子串不是子序列）。

### 解题思路：不定长窗口 + 哈希记下标

窗口多长不知道（要求的就是最长），所以是不定长窗口，套路固定：**右指针贪心扩张（窗口越长越好），一旦违规（出现重复字符），左端收缩到重新合法为止**。

收缩可以更快：用 `map[byte]int` 记录每个字符**最后一次出现的下标**。当 s[right] 在窗口内重复时，left 直接**跳**到"重复字符上次出现位置的下一格"——因为重复字符左边的任何起点都注定无效，一格一格缩是浪费。

```
s = "abcabcbb"

 right →  0  1  2  3  4  5  6  7
          a  b  c  a  b  c  b  b

 right=0 'a'：无重复，窗口 [0,0]  "a"    长度 1
 right=1 'b'：无重复，窗口 [0,1]  "ab"   长度 2
 right=2 'c'：无重复，窗口 [0,2]  "abc"  长度 3 ✔
 right=3 'a'：'a' 在下标 0 出现过（>= left）
             left 跳到 0+1=1，窗口 [1,3] "bca" 长度 3
 right=4 'b'：'b' 在下标 1，left 跳到 2，"cab"  长度 3
 right=5 'c'：'c' 在下标 2，left 跳到 3，"abc"  长度 3
 right=6 'b'：'b' 在下标 4，left 跳到 5，"cb"   长度 2
 right=7 'b'：'b' 在下标 6，left 跳到 7，"b"    长度 1
 答案 3
```

注意 `idx >= left` 这个判断：字符虽出现过，但如果出现在**窗口外**（left 之前），不算重复，left 不能往回跳。经典反例 `"abba"`：扫到最后一个 'a' 时它的记录下标是 0，但 left 已经是 2，若回跳到 1 就把 "bba" 当合法窗口了——错。

left 只前进不后退的单调性保证了复杂度：每个字符进窗、出窗各一次，O(n)。

### 代码（跳格版：记下标直接跳）

```go
package main

import "fmt"

func lengthOfLongestSubstring(s string) int {
	last := make(map[byte]int) // 字符 -> 最后一次出现的下标
	ans := 0
	left := 0 // 窗口左端（当前无重复段的起点）
	for right := 0; right < len(s); right++ {
		c := s[right]
		if idx, ok := last[c]; ok && idx >= left { // 重复且在窗口内
			left = idx + 1 // 跳到重复字符的下一格
		}
		last[c] = right
		if right-left+1 > ans { // 每轮都结算窗口长度
			ans = right - left + 1
		}
	}
	return ans
}

func main() {
	fmt.Println(lengthOfLongestSubstring("abcabcbb")) // 3
	fmt.Println(lengthOfLongestSubstring("bbbbb"))   // 1
	fmt.Println(lengthOfLongestSubstring("pwwkew"))  // 3
	fmt.Println(lengthOfLongestSubstring("abba"))    // 2
}
```

### 代码（模板版：三件套写法）

上面是"跳格"优化版。更通用、更好记的是滑动窗口标准三件套——**右端进窗 → 违规收缩 → 结算**，适合任何不定长窗口题（最长子串、最多含 k 种字符等一套通吃）：

```go
package main

import "fmt"

func lengthOfLongestSubstringTemplate(s string) int {
	cnt := make(map[byte]int) // 窗口内每个字符的出现次数
	ans := 0
	left := 0
	for right := 0; right < len(s); right++ {
		cnt[s[right]]++                    // 1. 右端进窗
		for cnt[s[right]] > 1 {            // 2. 违规：当前字符重复
			cnt[s[left]]-- // 左端出窗
			left++
		}
		if right-left+1 > ans { // 3. 收缩完必合法，结算
			ans = right - left + 1
		}
	}
	return ans
}

func main() {
	fmt.Println(lengthOfLongestSubstringTemplate("abcabcbb")) // 3
	fmt.Println(lengthOfLongestSubstringTemplate("abba"))    // 2
}
```

### 解法对比

| | 暴力（每个起点截伸） | 跳格版 | 模板版 |
|---|---|---|---|
| 时间 | O(n²) ~ O(n³) | O(n) | O(n)（左端一格一格缩，均摊仍 O(n)） |
| 空间 | O(1) ~ O(n) | O(min(n, 字符集)) | O(min(n, 字符集)) |
| 特点 | 面试保底 | 收缩一步到位，最快 | 换违规条件就迁移到别的题 |

### 复杂度

| 指标 | 值 | 说明 |
|------|----|------|
| 时间 | O(n) | left/right 各自单调前进，每字符进出窗各一次 |
| 空间 | O(min(n, Σ)) | Σ 是字符集大小，纯小写字母时 O(26) |

### 易错点

1. **`idx >= left` 判断不能少**：出现过 ≠ 在窗口内，`"abba"` 是必测反例。
2. left 是跳到 `idx + 1`，不是 `idx`。
3. `ans` 和 `last[c]` **每轮都要更新**，别只在命中重复时更新。
4. 题目求的是子串（连续），不是子序列——被问懵过的人不在少数。

### 🎤 口述模板

"不定长滑动窗口：右指针不断扩张把窗口撑大，用 map 记录每个字符最后一次出现的下标；一旦新字符在窗口内重复，左边界直接跳到它上次出现位置的下一格——重复字符左边的起点全都无救，跳过去是安全的。因为左边界只前进不后退，每个字符进出窗口各一次，整体 O(n)。注意要判断记录的下标是否还在窗口内，经典反例是 abba。"

## 本组小结

| 题号 | 窗口类型 | 维护的状态 | 违规条件 |
|---|---|---|---|
| LC438 | 定长 | 窗口计数数组 | （无，直接比对指纹） |
| LC3 | 不定长求最长 | 字符 → 最后下标 | 出现重复字符 |

一句话：窗口宽度已知用定长（进一个出一个）；窗口宽度是答案就用"右扩 + 违规左缩"三件套。判定的前提是单调性——右扩只会让条件更容易违规、左缩只会更宽松，不满足就别硬滑。
