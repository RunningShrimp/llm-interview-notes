## 1｜LC94 二叉树的中序遍历（简单）

**题干**：给二叉树根节点 `root`，返回中序遍历（左→根→右）的节点值数组。进阶：不用递归，用迭代。

### 解题思路：递归三行，迭代才是面试点

递归版闭眼写。但面试官一定会追："递归的本质是什么？"——是**函数调用栈**。所以迭代版要自己维护一个栈，模拟递归压栈。中序的难点在于：**根不能进门就访问，得等左子树全部出栈后才能访问**。于是套路是"一路向左压栈 → 栈顶弹出即访问 → 转向右子树继续压左"：

```text
      1          栈的变化：压1 → 压2 → 压4 → 弹4(访) → 弹2(访)
     / \                   → 压5 → 弹5(访) → 弹1(访) → 压3 → 弹3(访)
    2   3        输出：4 2 5 1 3
   / \
  4   5
```

```go
package main

// 迭代栈版（面试主推）
func inorderTraversal(root *TreeNode) []int {
	res := []int{}
	stack := []*TreeNode{}
	cur := root
	for cur != nil || len(stack) > 0 {
		for cur != nil { // 一路向左压栈
			stack = append(stack, cur)
			cur = cur.Left
		}
		cur = stack[len(stack)-1] // 栈顶：左子树已处理完
		stack = stack[:len(stack)-1]
		res = append(res, cur.Val) // 弹出即访问（中序的"根"在这里）
		cur = cur.Right            // 转向右子树，下一轮继续压左
	}
	return res
}

// 递归对比版：三行写完，但讲不清栈就露馅
func inorderTraversalRecursive(root *TreeNode) []int {
	var res []int
	var dfs func(*TreeNode)
	dfs = func(n *TreeNode) {
		if n == nil {
			return
		}
		dfs(n.Left)         // 左
		res = append(res, n.Val) // 根
		dfs(n.Right)        // 右
	}
	dfs(root)
	return res
}
```

| 解法   | 时间 | 空间  | 备注                      |
|--------|------|-------|---------------------------|
| 递归   | O(n) | O(n)  | 栈深=树高，最坏链状 O(n)  |
| 迭代栈 | O(n) | O(n)  | 显式栈，树高超深时更安全  |

**易错点**：① 外层循环条件是 `cur != nil || len(stack) > 0` 两个条件取或——只写栈非空会在根节点时直接退出；② 弹出访问后必须 `cur = cur.Right` 而不是继续用栈。

🎤 **口述模板**：「中序递归就是左根右三行；迭代版我手动维护栈模拟递归调用栈：当前节点非空就一直往左压栈，然后弹栈访问，再转向右子树。循环条件是当前节点和栈至少一个非空，因为转向右子树后 cur 可能是 nil 但栈里还有待访问的祖先。」

## 2｜LC104 二叉树的最大深度（简单）

**题干**：给根节点 `root`，返回最大深度（根到最远叶子节点路径上的节点数）。

### 解题思路：一句递归定义 + BFS 数层数

深度的定义本身就是递归的：**我的深度 = 1 + max(左深度, 右深度)**。这就是后序（先问孩子要答案，再算自己的）。BFS 版则更"工程"：一层一层处理，处理了几层深度就是几——这是层序遍历 LC102 的直系应用。

```text
      3           DFS 视角：depth(3)=1+max(depth(9), depth(20))
     / \                    = 1+max(1, 2) = 3
    9  20        BFS 视角：第1层[3] 第2层[9,20] 第3层[15,7] → 3 层
      /  \
     15   7
```

```go
package main

// 解法一：DFS 后序递归——把问题翻译成定义本身
func maxDepthDFS(root *TreeNode) int {
	if root == nil {
		return 0 // 空树深度 0（约定：叶子为 1）
	}
	l := maxDepthDFS(root.Left)
	r := maxDepthDFS(root.Right)
	if l > r {
		return l + 1
	}
	return r + 1
}

// 解法二：BFS 层序——每轮循环处理完整的一层，层数即深度
func maxDepthBFS(root *TreeNode) int {
	if root == nil {
		return 0
	}
	depth := 0
	queue := []*TreeNode{root}
	for len(queue) > 0 {
		depth++                    // 进入新一层
		n := len(queue)            // 先记录本层节点数！
		for i := 0; i < n; i++ {   // 只处理本层的 n 个
			node := queue[0]
			queue = queue[1:]
			if node.Left != nil {
				queue = append(queue, node.Left)
			}
			if node.Right != nil {
				queue = append(queue, node.Right)
			}
		}
	}
	return depth
}
```

| 解法 | 时间 | 空间 | 备注                            |
|------|------|------|---------------------------------|
| DFS  | O(n) | O(h) | 栈深=树高，链状树最坏 O(n)      |
| BFS  | O(n) | O(w) | 队列最大=最宽一层节点数 w       |

**易错点**：① BFS 必须在循环开头把 `len(queue)` 存进临时变量 `n`——循环里 append 会改变队列长度，直接用 `len(queue)` 会把下层节点也当本层处理；② 空树约定返回 0，单节点返回 1（路径上的**节点数**，不是边数）。

🎤 **口述模板**：「DFS 就是把深度的递归定义翻译成代码：空返回 0，否则 1 加左右子树深度的较大值，天然是后序。BFS 则是标准层序模板，每轮处理一整层、深度加一，关键是在处理前先固定本层的节点数，防止新入队的孩子混进本层。」

## 3｜LC226 翻转二叉树（简单）

**题干**：给根节点 `root`，翻转整棵树（每个节点的左右子树互换），返回根。

### 解题思路：整棵树的"原子操作"就是交换一对孩子

翻转 = 每个节点都执行"左换右"。对任何一个节点，先递归翻转左子树、右子树（后序，孩子先翻好），再把两个翻好的孩子交换——也可以先交换再递归（前序），结果一样。这题是"把问题拆成根+左右子树"的最纯样本：

```text
       4                  4
      / \       翻转     / \
     2   7     ─────→   7   2
    / \ / \            / \ / \
   1  3 6  9          9  6 3  1
```

```go
package main

// 后序版：孩子先翻好，我再交换（推荐，最好解释）
func invertTree(root *TreeNode) *TreeNode {
	if root == nil {
		return nil
	}
	left := invertTree(root.Left)   // 先把左子树整体翻好
	right := invertTree(root.Right) // 再把右子树整体翻好
	root.Left = right               // 交换两个"已翻好"的孩子
	root.Right = left
	return root
}

// 前序版对比：进门先交换，再递归——结果相同
func invertTreePre(root *TreeNode) *TreeNode {
	if root == nil {
		return nil
	}
	root.Left, root.Right = root.Right, root.Left // 先交换
	invertTreePre(root.Left)                      // 再翻新左右
	invertTreePre(root.Right)
	return root
}
```

| 解法 | 时间 | 空间 |
|------|------|------|
| 递归（前/后序均可） | O(n) | O(h)，链状树最坏 O(n) |

**易错点**：① 交换必须用多重赋值 `a, b = b, a` 或临时变量，逐行赋值会覆盖；② 别忘了 `return root`——要返回根，不只是改结构；③ 空节点直接返回，无需处理。

🎤 **口述模板**：「翻转二叉树就是每个节点做一次左右孩子交换。我用后序写：递归拿到翻好的左子树和右子树，再赋值互换，返回根。前后序都能过，唯独中序不行——中序会把右子树翻两次。」

## 4｜LC101 对称二叉树（简单）

**题干**：判断二叉树是否轴对称（沿根的垂直线折叠能重合）。

### 解题思路：一个参数判不了对称，得两个

单节点递归 `isSymmetric(root)` 很难描述"左边的左"要和"右边的右"比。破解法：**换递归函数的签名**——传两个节点 `(l, r)`，判断它们是否互为镜像：值相等，且 `l.Left` 与 `r.Right` 镜像、`l.Right` 与 `r.Left` 镜像。这是二叉树递归的重要心法：**递归参数不够就加**。

```text
        1                 比较顺序：(2,2)→(3,4)(4,3)
       / \                对称条件：值相等 + 外侧对称 + 内侧对称
      2   2                  外侧 = l.Left vs r.Right
     / \ / \               内侧 = l.Right vs r.Left
    3  4 4  3
```

```go
package main

func isSymmetric(root *TreeNode) bool {
	if root == nil {
		return true
	}
	return mirror(root.Left, root.Right)
}

// 双参数递归：判断 l、r 是否互为镜像
func mirror(l, r *TreeNode) bool {
	if l == nil && r == nil {
		return true // 同时为空，对称
	}
	if l == nil || r == nil {
		return false // 一空一非空，不对称
	}
	return l.Val == r.Val && // 值相等
		mirror(l.Left, r.Right) && // 外侧镜像
		mirror(l.Right, r.Left) // 内侧镜像
}
```

| 解法 | 时间 | 空间 |
|------|------|------|
| 双参数递归 | O(n) | O(h) |

**易错点**：① 最大的坑是写成 `mirror(l.Left, l.Right)` 单节点自比——对称是"跨轴"比较，必须两个指针从根的两边出发；② 空树是对称的，返回 true。

🎤 **口述模板**：「对称二叉树单参数递归描述不出来，所以我换签名：写一个双参数函数判断两个节点是否互为镜像——值相等，且左的左配右的右（外侧）、左的右配右的左（内侧）继续镜像。入口传根的左孩子和右孩子。」

## 5｜LC543 二叉树的直径（简单）

**题干**：二叉树直径 = 任意两节点间最长路径的**边数**（路径不一定经过根）。求直径。

### 解题思路：求深度是"分内事"，直径是"顺手统计的副产品"

直接想"任意两节点路径"会懵。换角度：**任何一条路径，都有一个"最高点"（拐弯处）**。以节点 x 为拐弯的路径长 = 左深度 + 右深度（边数）。所以遍历每个节点当一次拐弯点，取最大值——而求每个节点的左右深度正是后序。于是：**后序递归算深度，返回给父节点的是深度，但路上顺手用 `左深+右深` 更新全局最大直径**。

```text
          1                 节点1做拐弯：左深1 + 右深2 = 3
         / \                节点3做拐弯：0 + 0 ... 
        2   3               节点2做拐弯：左深1 + 右深1 = 2
       / \                  全局最大 = 3 → 直径 3（路径 4-2-1-3 或 5-2-1-3）
      4   5
```

```go
package main

func diameterOfBinaryTree(root *TreeNode) int {
	ans := 0 // 全局最大直径（边数）
	var depth func(*TreeNode) int
	depth = func(n *TreeNode) int {
		if n == nil {
			return 0
		}
		l := depth(n.Left)  // 左子树深度
		r := depth(n.Right) // 右子树深度
		if l+r > ans {      // 顺手统计：以 n 为拐弯的路径边数 = l + r
			ans = l + r
		}
		if l > r { // 返回给父节点的是"深度"（边数），二选一大
			return l + 1
		}
		return r + 1
	}
	depth(root)
	return ans
}
```

| 解法     | 时间 | 空间 | 备注                          |
|----------|------|------|-------------------------------|
| 后序+全局 | O(n) | O(h) | 每个节点只访问一次            |

**易错点**：① **返回值和统计值是两个东西**！返回给父的是深度（只能选一边），统计进答案的是 `l + r`（两边相加）——这是本题最核心的区分，LC124 会原样复用这个骨架；② 直径按**边数**算，别把根也算成 1。

🎤 **口述模板**：「任何路径都有个最高拐弯点。我后序遍历，每个节点算左右子树深度，顺手用左右深度之和更新全局最大直径，但返回给父节点的只是深度加一——'统计用和、返回取大'，这个区分讲清楚，后面 LC124 就是同一个骨架换负数处理。」

## 6｜LC102 二叉树的层序遍历（中等）

**题干**：给根节点 `root`，返回按层组织的节点值数组 `[[层1],[层2],...]`（从左到右）。

### 解题思路：队列 + 按层切分——所有 BFS 题的母版

普通 BFS 一股脑出队入队分不出层。技巧：**每轮循环开始前记录当前队列长度 n，这个 n 恰好就是"本层节点数"**（上层节点全出队后，队列里剩下的正是本层全部）。循环 n 次处理完一层。这题是模板题，LC199 右视图、LC104 BFS 版都是它的变体。

```text
       3         队列演变：
      / \        初始 [3]        → 本层 [3]
     9  20       切分 → [9,20]    → 本层 [9,20]
    /  \         切分 → [15,7]    → 本层 [15,7]
   15   7       输出 [[3],[9,20],[15,7]]
```

```go
package main

func levelOrder(root *TreeNode) [][]int {
	res := [][]int{}
	if root == nil {
		return res
	}
	queue := []*TreeNode{root}
	for len(queue) > 0 {
		n := len(queue)          // 关键：先固定本层节点数
		level := make([]int, 0, n)
		for i := 0; i < n; i++ { // 恰好处理完一层
			node := queue[0]
			queue = queue[1:]
			level = append(level, node.Val)
			if node.Left != nil {
				queue = append(queue, node.Left) // 孩子进队=下层
			}
			if node.Right != nil {
				queue = append(queue, node.Right)
			}
		}
		res = append(res, level) // 一层收集完
	}
	return res
}
```

| 解法     | 时间 | 空间 | 备注                     |
|----------|------|------|--------------------------|
| BFS 队列 | O(n) | O(w) | w=最宽层节点数           |

**易错点**：① 和 LC104 同一个坑：`n := len(queue)` 必须在内层循环前取出；② 空树直接返回空切片，不要返回 nil 也别 panic；③ Go 里 `queue = queue[1:]` 会移动底层数组指针，这里规模小可接受，面试提一句"可用头指针 idx 优化切片复制"是加分项。

🎤 **口述模板**：「层序遍历就是队列 BFS 加按层切分：每轮循环开始记下队列长度作为本层节点数，内层循环正好弹出这一层并把孩子全部入队。这个模板能直接改出右视图取层尾、锯齿形反转奇数层、最深层层数等一整族题。」

## 7｜LC108 将有序数组转换为二叉搜索树（简单）

**题干**：给升序数组 `nums`，将其转成一棵**高度平衡**的 BST，返回根。

### 解题思路：升序=中序，中点做根天然平衡

BST 的中序遍历是升序——所以这是"给中序还原 BST"。但中序不唯一，题目要**平衡**：那就不玩花的，**每次取区间中点做根**，左边全做左子树、右边全做右子树，两边规模差最多 1，天然平衡。递归二分，闭区间 `[l, r]`，`l > r` 返回 nil。

```text
  [-10,-3,0,5,9]
        ↑中点0做根
   [-10,-3]    [5,9]
      ↑-3       ↑9(偶数长度取右中点，取左也行)
   [-10]      [5]
```

```go
package main

func sortedArrayToBST(nums []int) *TreeNode {
	var build func(l, r int) *TreeNode
	build = func(l, r int) *TreeNode {
		if l > r {
			return nil // 空区间
		}
		mid := l + (r-l)/2        // 中点做根（防溢出写法）
		node := &TreeNode{Val: nums[mid]}
		node.Left = build(l, mid-1)  // 左半做左子树
		node.Right = build(mid+1, r) // 右半做右子树
		return node
	}
	return build(0, len(nums)-1)
}
```

| 解法       | 时间 | 空间 | 备注                        |
|------------|------|------|-----------------------------|
| 中点二分   | O(n) | O(log n) | 递归栈深=树高=log n     |

**易错点**：① 边界用闭区间 `[l, r]`，终止条件 `l > r`（不是 `>=`）；② 偶数长度中点取左取右都对，答案不唯一，LeetCode 两种都判对；③ `l+(r-l)/2` 防溢出是老生常谈的加分写法。

🎤 **口述模板**：「升序数组就是 BST 的中序遍历，要平衡就每次取区间中点做根：左边递归做左子树，右边递归做右子树，两边节点数差最多一，高度差不超过一，天然平衡。闭区间递归，l 大于 r 返回空。」

## 8｜LC98 验证二叉搜索树（中等）

**题干**：判断给定二叉树是否是合法 BST（**所有**左子树节点 < 根 < **所有**右子树节点）。

### 解题思路：两个角度，都要会

**角度一（性质）**：BST 中序遍历严格递增 → 边中序边和前驱比较。
**角度二（定义）**："所有左 < 根"说明只比较父子不够，必须**上下界夹逼**：递归 `(node, low, high)`，节点值必须在开区间 `(low, high)` 内，进左子树收紧上界为当前值，进右子树收紧下界。

```text
    5            只比父子：4 < 3? 不成立？看下面反例
   / \
  1   6         这棵树 6 的右子树 3：
     / \        父子都合法(3<6)，但 3 < 根5 不合法 → 必须上下界
    4?  7?      左子树里藏大值同理
```

```go
package main

import "math"

// 解法一：中序递增——prev 记前驱，当前必须严格大于 prev
func isValidBSTInorder(root *TreeNode) bool {
	prev := math.Inf(-1)
	var inorder func(*TreeNode) bool
	inorder = func(n *TreeNode) bool {
		if n == nil {
			return true
		}
		if !inorder(n.Left) {
			return false
		}
		if float64(n.Val) <= prev { // 不是严格递增，非法
			return false
		}
		prev = float64(n.Val) // 更新前驱
		return inorder(n.Right)
	}
	return inorder(root)
}

// 解法二：上下界夹逼——推荐，更能体现"定义"理解
func isValidBSTRange(root *TreeNode) bool {
	var valid func(n *TreeNode, low, high int) bool
	valid = func(n *TreeNode, low, high int) bool {
		if n == nil {
			return true
		}
		if n.Val <= low || n.Val >= high { // 开区间 (low, high)
			return false
		}
		return valid(n.Left, low, n.Val) && // 左子树上界收紧为本值
			valid(n.Right, n.Val, high) // 右子树下界收紧为本值
	}
	return valid(root, math.MinInt64, math.MaxInt64)
}
```

| 解法       | 时间 | 空间 | 特点                               |
|------------|------|------|------------------------------------|
| 中序递增   | O(n) | O(h) | 借"中序=升序"性质，可提前终止      |
| 上下界     | O(n) | O(h) | 直接翻译定义，边界传参讲得最清楚   |

**易错点**：① **严格小于**：相等也不行，比较用 `<=` / `>=` 判非法；② 上下界初始值要能兜住 `math.MinInt64/MaxInt64`（所以传的是 int64 极值而非 0），更稳妥的做法是传 `*int` nil 表示无界；③ 单比较父子不合法——左子树的右孩子可能大于根（见上面 ASCII 图）。

🎤 **口述模板**：「验证 BST 我有两个解法。一是用性质：中序遍历严格递增，维护前驱值，出现小于等于前驱就非法。二是直接翻译定义：递归带上下界，节点必须在开区间内，进左子树把上界收紧成当前值，进右子树收紧下界——这样'所有左子树都小于根'才被真正保证。只比父子关系是这题的经典错误。」

## 9｜LC230 二叉搜索树中第 K 小的元素（中等）

**题干**：给 BST 根和整数 `k`，返回树中第 `k` 小的值（1 ≤ k ≤ 节点数）。

### 解题思路：BST + "第K小" = 中序遍历数到第 k 个

中序遍历 BST 就是升序访问，第 `k` 个访问的就是答案。加分点：**提前终止**——用迭代栈可以数够 k 个就停，不用遍历全树（均摊更接近 O(h+k)）。进阶追问（追求 O(log n) 可做懒更新节点计数）只需口头知道。

```go
package main

func kthSmallest(root *TreeNode, k int) int {
	stack := []*TreeNode{}
	cur := root
	for cur != nil || len(stack) > 0 {
		for cur != nil { // 一路向左（先访问最小的）
			stack = append(stack, cur)
			cur = cur.Left
		}
		cur = stack[len(stack)-1]
		stack = stack[:len(stack)-1]
		k--             // 弹出一个 = 消耗一个"第 k 小"名额
		if k == 0 {     // 恰好第 k 个
			return cur.Val
		}
		cur = cur.Right
	}
	return -1 // 题目保证 k 合法，走不到这
}
```

| 解法       | 时间     | 空间 | 备注                          |
|------------|----------|------|-------------------------------|
| 迭代中序   | O(h + k) | O(h) | 数到 k 即停，提前终止         |
| 递归中序   | O(n)     | O(h) | 写法更短但难提前 return       |

**易错点**：① `k` 递减时注意弹出一个节点消耗一个名额，判断在赋 `cur = cur.Right` **之前**；② 别忘了这题是 1-indexed（k=1 就是最小值）。

🎤 **口述模板**：「BST 的中序遍历就是升序，所以第 k 小就是中序遍历数到第 k 个。我用迭代栈版：压左、弹出、计数减一，减到零直接返回当前值——比递归好的地方是能真正提前终止，均摊 O 树高加 k。」

## 10｜LC199 二叉树的右视图（中等）

**题干**：返回从二叉树右侧能看到的节点值（每层最右边的节点）。

### 解题思路：右视图 = 每层的层尾

BFS 版：LC102 模板原样拿来，**每层循环的最后一个元素**（`i == n-1` 时）收入结果。DFS 版也能做：按"根→右→左"顺序先走右路，每层第一个到达的节点就是最右节点——用"当前深度 == 结果长度"判断首次到达。

```text
       1         <── 右视图：1 3 7（注意不是"一路向右"！）
      / \               第2层最右是 3，第3层最右是 7
     2   3
      \    \
       5    7    ← 若 7 不存在则第3层看到的是 5
```

```go
package main

// 解法一：BFS 取层尾（最好想）
func rightSideView(root *TreeNode) []int {
	res := []int{}
	if root == nil {
		return res
	}
	queue := []*TreeNode{root}
	for len(queue) > 0 {
		n := len(queue)
		for i := 0; i < n; i++ {
			node := queue[0]
			queue = queue[1:]
			if i == n-1 { // 本层最后一个 = 右视图看到的
				res = append(res, node.Val)
			}
			if node.Left != nil {
				queue = append(queue, node.Left)
			}
			if node.Right != nil {
				queue = append(queue, node.Right)
			}
		}
	}
	return res
}

// 解法二：DFS 根右左——每层第一个被访问的就是最右
func rightSideViewDFS(root *TreeNode) []int {
	res := []int{}
	var dfs func(n *TreeNode, depth int)
	dfs = func(n *TreeNode, depth int) {
		if n == nil {
			return
		}
		if depth == len(res) { // 该深度首次到达 → 必是最右
			res = append(res, n.Val)
		}
		dfs(n.Right, depth+1) // 先右！
		dfs(n.Left, depth+1)
	}
	dfs(root, 0)
	return res
}
```

| 解法 | 时间 | 空间 | 特点                             |
|------|------|------|----------------------------------|
| BFS  | O(n) | O(w) | 直观，模板复用 LC102            |
| DFS  | O(n) | O(h) | "深度==len(res)" 判首次是个妙招  |

**易错点**：① 右视图 ≠ 一直往右走——左子树更深处也可能被看到（见 ASCII 图：若 7 缺席就是 5）；② DFS 版必须先递归 Right 再 Left，顺序反了变左视图。

🎤 **口述模板**：「右视图就是每层最右节点。BFS 直接套层序模板，内层循环到最后一个时收集即可。DFS 版更有意思：按根右左先走右路，用'当前深度等于结果长度'识别每层第一次到达的节点，那个必然是最右的。」

## 11｜LC114 二叉树展开为链表（中等）

**题干**：把二叉树按前序顺序展开成"链表"：仍用 TreeNode，每个节点 `Left` 为 nil，`Right` 指向下一个节点。

### 解题思路：后序——先拉平左右，再三步拼装

对每个节点：① 递归把左子树拉平成链、右子树拉平成链（后序，孩子先处理好）；② 把拉平的左链挂到右边；③ 原右链拼到新右链末尾；④ 左边清空。

```text
      1            步骤（对节点1）：
     / \           ① 拉平: 左=2→3→4  右=5→6
    2   5          ② 左链挂右: 1→2→3→4
   / \   \         ③ 旧右链(5→6)接到 4 后面
  3   4   6        ④ 结果: 1→2→3→4→5→6
```

```go
package main

func flatten(root *TreeNode) {
	if root == nil {
		return
	}
	flatten(root.Left)  // ① 左子树先拉平
	flatten(root.Right) // ① 右子树先拉平（后序）
	left := root.Left
	right := root.Right
	root.Left = nil   // ④ 左边清空
	root.Right = left // ② 拉平的左链挂到右边
	p := root         // ③ 走到新右链末尾，拼上旧右链
	for p.Right != nil {
		p = p.Right
	}
	p.Right = right
}
```

| 解法     | 时间 | 空间 | 备注                        |
|----------|------|------|-----------------------------|
| 后序递归 | O(n) | O(h) | 每层找尾最坏 O(n)；整体 O(n²) 极端链状 |
| （进阶）前驱反转法 | O(n) | O(1) | 空间 O(1)，口头提一句加分    |

**易错点**：① 必须先把 `root.Right` 存进临时变量再改 `root.Right = left`，否则旧右链被覆盖丢失；② `root.Left = nil` 别忘；③ 面试追问 O(1) 空间：从根往下，遇有左孩子的节点就把左链插入右路（经典 Morris 变体），能说出思路即可。

🎤 **口述模板**：「展开是前序的顺序，但我用后序做：先把左右子树各自递归拉平成链，然后把左链换到右边、旧右链接到新右链尾部、左指针清空。注意先把旧右链存临时变量防止覆盖丢失。追问 O(1) 空间时可以说前驱插入的 Morris 思路。」

## 12｜LC105 从前序与中序遍历序列构造二叉树（中等）

**题干**：给前序 `preorder` 和中序 `inorder`（节点值可重复性：无重复），还原二叉树并返回根。

### 解题思路：前序定根，中序分割

两个序列分工明确：**前序第一个元素必是根**；**中序里根的位置把序列切成左子树|右子树两段**。递归下去：由左子树节点数在前序里同步切出对应区间，各造各的。加速点：先**哈希表预存"值→中序下标"**，每层 O(1) 定位根，否则每次线性扫是 O(n²)。

```text
  pre: [3,9,20,15,7]   根=3
  in:  [9,3,15,20,7]   ←哈希定位 3 在下标1
         │ └────┬───┘
   左子树[9]  右子树[15,20,7]
   (下标0~0)  (下标2~4)
       3
      / \        再递归：pre[1..1]=[9] ↔ in[9]
     9  20       pre[2..4]=[20,15,7] ↔ in[15,20,7]，根=20...
```

```go
package main

func buildTree(preorder []int, inorder []int) *TreeNode {
	idx := make(map[int]int, len(inorder)) // 值 → 中序下标，O(1) 定位
	for i, v := range inorder {
		idx[v] = i
	}
	var build func(preL, preR, inL, inR int) *TreeNode
	build = func(preL, preR, inL, inR int) *TreeNode {
		if preL > preR {
			return nil
		}
		root := &TreeNode{Val: preorder[preL]} // 前序区间头 = 根
		mid := idx[root.Val]                   // 根在中序的位置
		leftLen := mid - inL                   // 左子树节点数
		root.Left = build(preL+1, preL+leftLen, inL, mid-1)
		root.Right = build(preL+leftLen+1, preR, mid+1, inR)
		return root
	}
	return build(0, len(preorder)-1, 0, len(inorder)-1)
}
```

| 解法       | 时间 | 空间 | 备注                             |
|------------|------|------|----------------------------------|
| 哈希+区间递归 | O(n) | O(n) | 哈希 O(n)，递归栈 O(h)         |

**易错点**：① 四个区间参数别搞混——**左子树前序区间长度 = 左子树中序区间长度**，用 `leftLen` 对齐是核心；② 前序区间头是根，但 `preL+1` 才是左子树起点；③ 有重复值时此法失效（哈希键冲突），题目保证了无重复。

🎤 **口述模板**：「前序第一个值是根，哈希表 O(1) 找到它在中序的位置，左边全是左子树、右边全是右子树；再用左子树节点数把前序区间同步切开，闭区间递归。没有哈希每次线性找根会退化到 n 方。」

## 13｜LC437 路径总和 III（中等）

**题干**：给根和 `targetSum`，统计**节点值之和等于 targetSum 的路径条数**。路径只能从上往下（父到子），不需要从根开始、不需要到叶子，但必须向下。

### 解题思路：LC560 的前缀和，原封不动搬上树

「数有多少段连续和 = k」在数组里用前缀和 + 哈希（LC560）。树上的路径也是"从某个祖先一路向下"，同样满足**前缀和之差 = 路径和**：走到节点 x 记 `cur = 根到x的和`，查哈希表里有多少祖先前缀等于 `cur - target`，就有多少条以 x 结尾的合法路径。关键新增动作：**回溯**——离开 x 时把它贡献的前缀从哈希里删掉，否则会算进"别的分支"的路径（那就不连续了）。

```text
  target=8, 路径 [5,3] 从 3 到 5：前缀(5)=10，前缀(3)=2 → 10-2=8 ✓
        10
       /  \
      5   -3
     / \    \
    3   2   11
   / \   \
  3  -2   1
  合法路径: [5,3] [5,2,1] [-3,11] [10,-3,11] → 共 4 条
```

```go
package main

func pathSum(root *TreeNode, targetSum int) int {
	prefix := map[int]int{0: 1} // 空路径：和为 0 出现 1 次
	var dfs func(n *TreeNode, cur int) int
	dfs = func(n *TreeNode, cur int) int {
		if n == nil {
			return 0
		}
		cur += n.Val                       // 根到当前节点的前缀和
		cnt := prefix[cur-targetSum]       // 多少祖先前缀能配对
		prefix[cur]++                      // 我的前缀入表
		cnt += dfs(n.Left, cur)            // 左右分支分别统计
		cnt += dfs(n.Right, cur)
		prefix[cur]--                      // 回溯：撤掉我的前缀！
		return cnt
	}
	return dfs(root, 0)
}
```

| 解法       | 时间 | 空间 | 备注                                   |
|------------|------|------|----------------------------------------|
| 前缀和+回溯 | O(n) | O(n) | 哈希存各分支活跃前缀，栈深 O(h)      |
| 双重递归   | O(n²) | O(h) | 每个节点都当一次起点，好想但慢        |

**易错点**：① **忘了回溯**是最常见 bug：不删 `prefix[cur]` 会把左分支的前缀配给右分支，路径就不连续了；② 哈希初值 `{0:1}` 必须有——"从根开始恰好等于 target"的前缀配对对象是空前缀；③ targetSum 与节点值都可能为负，不能剪枝提前退出。

🎤 **口述模板**：「这题就是树版 LC560：路径和等于前缀和之差。DFS 维护根到当前节点的前缀和，查哈希里有多少个祖先前缀等于当前前缀减 target，就是以当前节点结尾的路径数。树和数组的区别是路径会分叉，所以递归返回前必须把当前前缀从哈希里减回去回溯，防止串到别的分支。」

## 14｜LC236 二叉树的最近公共祖先（中等）★ 高频

**题干**：给根和两节点 `p`、`q`（保证存在于树中），找它们的最近公共祖先（同时是两者祖先且深度最大的节点；节点可以是自己的祖先）。

### 解题思路：后序"汇报"——左右都有答案，我就是 LCA

递归含义先定义清：`lowest(root,p,q)` = 在 root 子树里找 LCA，找到返回该节点，否则 nil。三种情况：

```text
① 左右子树各报回一个(p/q 分居两侧) → 我就是 LCA（后序汇总点！）
     L
    / \
   p   q        L 的左返回 p，右返回 q → L 是答案

② 只有一边报回非 nil → 答案在那一支，直接透传
③ 我自己就是 p 或 q → 返回我（祖先可以是自身）
     q
      \
       x        全树找 (q,x)：q 直接被返回并一路透传到根 → LCA=q
```

为什么"找到就透传"是对的？若 p 在 q 的上方，q 就是 LCA（自己是自己的祖先）；若 p、q 分居两侧，透传的会在共同祖先处"撞车"触发情况①。两条规则合起来刚好覆盖所有情形，**且每个节点只访问一次**。

```go
package main

func lowestCommonAncestor(root, p, q *TreeNode) *TreeNode {
	if root == nil || root == p || root == q {
		return root // 情况③：碰到 p/q 或空，直接上报
	}
	left := lowestCommonAncestor(root.Left, p, q)   // 问左子树
	right := lowestCommonAncestor(root.Right, p, q) // 问右子树
	if left != nil && right != nil { // 情况①：两边都报 → 我就是 LCA
		return root
	}
	if left != nil { // 情况②：只有左边有 → 透传
		return left
	}
	return right
}
```

| 解法     | 时间 | 空间 | 备注                                   |
|----------|------|------|----------------------------------------|
| 后序递归 | O(n) | O(h) | 面试标准答案                          |
| 父指针法 | O(n) | O(n) | 记录到根路径再对齐，思路同"链表交点"  |

**易错点**：① 判断 `root == p` 是**指针相等**，不是值相等（值可能重复）；② 别把"祖先可以是自身"漏了——q 在 p 子树内时答案就是 q；③ 这题普通二叉树**不能**用值大小比较（那是 BST 版 LC235 的特权，可用值剪枝到 O(h)）；④ 想不出递归时退路：哈希记每个节点的父指针，p 走到根标脏，q 上行第一个脏点即 LCA。

🎤 **口述模板**：「LCA 我用后序'汇报'：递归在左右子树里分别找 p 和 q。当前节点为空或就是 p/q 时直接上报自己；左右都报回非空，说明 p、q 分居两侧，当前节点就是 LCA；只有一边非空就透传那一边。这套规则覆盖了'互为祖先'的情况——p 在 q 上方时 q 自己就是答案，会一路透传上去。追问 BST 版就说可以按值走单边路径，O 树高。」

## 15｜LC124 二叉树中的最大路径和（困难）

**题干**：路径 = 任意节点到任意节点的序列（无需经过根/叶子，方向只能向下，即每对节点只有一条简单路径）。**路径至少含一个节点**，节点值可能为负，求最大路径和。

### 解题思路：LC543 的骨架 + 一个反直觉决策——负增益弃

与 LC543 完全同骨架：路径有最高拐弯点，以 x 为拐弯的路径和 = 左贡献 + x.Val + 右贡献，其中**贡献 = max(子树最大单边延伸, 0)**——子树延伸是负数宁可不要（负增益弃）。返回给父的仍是"单边延伸"：`x.Val + max(左贡献, 右贡献)`。**统计用两边和（可弃负），返回取单边（也可弃负）**——两处都要和 0 取大。

```text
        -10
        /  \        节点20做拐弯: 15+20+7 = 42（全局最大）
      9    20       节点-10做拐弯: max(9侧,0)+(-10)+42侧... 负的不要
          /  \      返回给父的是单边: 20+max(15,7)=35
         15   7     答案 42
```

```go
package main

import "math"

func maxPathSum(root *TreeNode) int {
	ans := math.MinInt // 至少含一个节点，初始为最小int防全负
	var gain func(n *TreeNode) int // gain = 从 n 向下的最大单边延伸(可弃负)
	gain = func(n *TreeNode) int {
		if n == nil {
			return 0
		}
		l := max(gain(n.Left), 0)  // 左贡献，负则弃（取0）
		r := max(gain(n.Right), 0) // 右贡献，负则弃
		if l+n.Val+r > ans {       // 拐弯统计：两边和 + 自身
			ans = l + n.Val + r
		}
		return n.Val + max(l, r) // 返回单边延伸（大的那边）
	}
	gain(root)
	return ans
}

func max(a, b int) int {
	if a > b {
		return a
	}
	return b
}
```

| 解法       | 时间 | 空间 | 与 LC543 对比                           |
|------------|------|------|------------------------------------------|
| 后序+全局  | O(n) | O(h) | 骨架相同，新增"负贡献取 0"和全负初始化  |

**LC543 vs LC124 一图看懂**：

```text
            LC543（边数）                LC124（带权和）
 统计       l + r                      max(l,0) + val + max(r,0)
 返回       max(l,r) + 1               val + max(l, r)     ← 都可能取0
 初始       0                          MinInt（全负树答案可为负）
 无负数烦恼 ✓                           ✓ 全负时要保证"至少一个节点"
```

**易错点**：① 全负树答案就是最大的那个负数节点——`ans` 必须初始化 `math.MinInt` 而不是 0；② 两处 max(...,0)：子树贡献为负要弃；③ 返回值是**单边**延伸不是拐弯和，把统计和返回混为一谈是这题最常见的 WA。

🎤 **口述模板**：「这题是 LC543 的加权版：还是后序求每个节点做拐弯时的路径和，等于左右贡献加自身，负贡献直接舍弃。但返回给父节点只能选一边，返回值和统计值是两条线。初始化用最小 int，因为答案可以是负数——树至少保留一个节点。」

## 章末收尾：二叉树套路总结表

| 信号词（题干里出现）        | 套路                         | 本组题目           |
|-----------------------------|------------------------------|--------------------|
| "层 / 每层 / 最短 / 视图"   | BFS 队列 + 固定层长切分      | LC102/199/104B     |
| "有序 / 第 K 小 / 验证 BST" | 中序（BST 的排序键）         | LC94/98/230        |
| "深度 / 直径 / 路径和 / 平衡" | 后序：孩子先汇报，再算自己  | LC104/543/124/236  |
| "构造 / 还原树"             | 定根 + 哈希定位 + 区间递归   | LC105/108          |
| "数路径条数（可中途起止）"  | 树上前缀和 + 回溯            | LC437（同 LC560）  |
| "翻转 / 对称"               | 递归换签名 / 逐点交换        | LC226/101          |

**三个最值钱的区分**（面试官最爱挖）：

1. **统计值 vs 返回值**（LC543/124）：拐弯统计用左右之和，返回父只给单边——骨架 `l+r 更新全局` + `max(l,r)+1/val 返回`。
2. **只比父子 vs 上下界**（LC98）：BST 合法性必须靠祖先链夹逼，局部比较必错。
3. **入表 vs 回溯出表**（LC437）：树上哈希要随递归回滚，否则跨分支串路径。

**一句话收官**：二叉树题不考聪明，考的是"你敢不敢把递归定义写成代码"。每题开工前先用决策图选遍历方式，写完检查三件事——空指针、返回值含义、全局变量初始化，这 15 题就都在射程内了。
