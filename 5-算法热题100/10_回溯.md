# 10｜回溯（LeetCode 热题 100 · 全 8 题）

> 回溯 = **带"撤销"动作的暴力 DFS**。它不是什么玄学，就是穷举一棵决策树：每层做一个选择，走不通就退回来换一个。热题 100 回溯组 8 道题，全是**同一棵树换不同的剪枝条件**——先把三步模板焊死，后面每题只是"填空"。

## 〇、回溯三步模板 + 决策树（开背）

```text
func backtrack(路径, 选择列表):
    if 满足结束条件:
        result.add(路径的拷贝)     // 注意是拷贝！
        return
    for 选择 in 选择列表:
        做选择          # ① 选择：path 加入、used 标记、计数 +1
        backtrack(...)  # ② 递归：进入下一层决策
        撤销选择        # ③ 撤销：path 弹出、used 复位、计数 -1
```

决策树长啥样？以 `nums=[1,2,3]` 里**选 2 个（组合）**为例，每个节点就是一条"路径"：

```text
                           []                 ← 第 0 层：一个都没选
            ┌──────────────┼──────────────┐
          选 1            选 2            选 3
           [1]             [2]             [3]
        ┌────┴────┐         └──┐             └──┐
      选 2      选 3         选 3              （没有可选的了）
     [1,2]✓    [1,3]✓       [2,3]✓

  ✓ = 长度到 2，收集进结果
  注意 [2] 那层只从"2 后面"选 → 不会冒出 [2,1]（这就是 start 去重）
```

看图说话，回溯三件套：

- **path 路径**：已经做出的选择（比如 `[1]`）；
- **选择列表**：当前还能选什么——**组合看 start，排列看 used**；
- **结束条件**：path 够长 / target 减到 0 / 走到串尾。

排列 vs 组合，一张表永久分清：

|          | 排列（LC46）           | 组合 / 子集（LC78 / 39）   |
|----------|------------------------|-----------------------------|
| 顺序敏感 | 敏感：`[1,2] ≠ [2,1]`  | 不敏感：`[1,2] = [2,1]`     |
| 防重复   | used 数组（用过跳过）  | start 起点（只往后看）      |
| 每层扫哪 | 全部（跳过 used 的）  | 从 start 到末尾             |

口诀：**排列用 used，组合用 start**。下面 6 题，全是在这棵树上换结束条件和剪枝。

## 1｜LC46 全排列（中等）

**题干**：给一个不含重复数字的数组 `nums`，返回其**全排列**（所有顺序都算不同结果）。

### 解题思路：used 数组盯住"谁用过"

排列的核心矛盾：**每个数只能用一次，但每层循环都要从头扫**。解法就是加一个 `used []bool`：扫描时跳过用过的，选择时标记、撤销时复位。

```text
nums=[1,2,3]，path=[]，used=[F,F,F]

[]
├─ 选1 used[T,F,F] → [1]
│   ├─ 选2 → [1,2] → 选3 → [1,2,3]✓
│   └─ 选3 → [1,3] → 选2 → [1,3,2]✓
├─ 选2 ...（对称，共 3! = 6 个叶子）
└─ 选3 ...

每层 for 从 i=0 扫，靠 used 跳过"祖先路径上已用的"
```

### 完整代码（used 数组）

```go
package main

// LC46 全排列：used 数组
func permute(nums []int) [][]int {
	res := [][]int{}
	path := []int{}
	used := make([]bool, len(nums))

	var backtrack func()
	backtrack = func() {
		if len(path) == len(nums) { // 排满 n 个，收工
			tmp := make([]int, len(path))
			copy(tmp, path) // 必须拷贝！path 底层数组会被后续复用
			res = append(res, tmp)
			return
		}
		for i := 0; i < len(nums); i++ {
			if used[i] { // 每层从头扫，但用过的不许再选
				continue
			}
			used[i] = true            // ① 选择
			path = append(path, nums[i])
			backtrack()                // ② 递归
			path = path[:len(path)-1]  // ③ 撤销
			used[i] = false
		}
	}
	backtrack()
	return res
}
```

### 复杂度

| 项目 | 复杂度      | 说明                            |
|------|-------------|---------------------------------|
| 时间 | O(n × n!)   | 共 n! 个排列，每个拷贝 O(n)     |
| 空间 | O(n)        | 递归栈 + used + path（不计结果）|

### 易错点

1. **收集 path 必须拷贝**：`res = append(res, path)` 存的是切片底层数组引用，回溯一改全毁——全组最经典的 bug。
2. used 的标记/复位必须**成对**出现在选择和撤销两侧，漏一个结果直接乱套。
3. 有重复数字的进阶版 LC47：先排序，同层重复值跳过（`used[i-1]==false && nums[i]==nums[i-1]`），面试常追问。
4. 结束条件是 `len(path) == len(nums)`，别写成固定数字。

### 🎤 口述模板

> "全排列用回溯：维护 path 和 used 数组，每层从头扫候选，用过的靠 used 跳过。选择时标记 used、追加 path，递归回来后弹出 path、复位 used。path 长度等于 n 时拷贝进结果。时间 n 乘 n 阶乘。如果有重复数字，先排序再做同层去重。"

## 2｜LC78 子集（中等）

**题干**：给一个不含重复元素的整数数组，返回其**所有子集**（幂集），解集中不能有重复子集。

### 解题思路一：start 起点剪枝（枚举"下一个选谁"）

子集和排列的唯一区别：**`[1,2]` 和 `[2,1]` 是同一个子集**。所以不能每层从头扫，而是传一个 `start`，**每层只从"上一次选的位置之后"扫**——天然保证组合字典序，绝不重复。另一个特点：**每个节点都是一个合法子集**（不只是叶子），所以进函数先收集，再扩展。

```text
nums=[1,2,3]
                 []✓            ← 进门先收集：空集也是子集
      ┌──────────┼──────────┐
     [1]✓       [2]✓        [3]✓
  ┌────┴───┐      └──┐        └──(start=3 无可选)
[1,2]✓  [1,3]✓    [2,3]✓
  └─[1,2,3]✓

共 2^3 = 8 个：[] [1] [2] [3] [1,2] [1,3] [2,3] [1,2,3]
```

### 完整代码（视角一：start 枚举）

```go
package main

// LC78 子集：start 起点剪枝
func subsets(nums []int) [][]int {
	res := [][]int{}
	path := []int{}

	var backtrack func(start int)
	backtrack = func(start int) {
		tmp := make([]int, len(path))
		copy(tmp, path)
		res = append(res, tmp) // 每个节点都是子集，进门先收集

		for i := start; i < len(nums); i++ { // 只往后看
			path = append(path, nums[i]) // ① 选择
			backtrack(i + 1)             // ② 递归：下一层从 i+1 起
			path = path[:len(path)-1]    // ③ 撤销
		}
	}
	backtrack(0)
	return res
}
```

### 解题思路二："选/不选"视角（每个元素二选一）

换个角度：不枚举"下一个选谁"，而是**对每个元素问一句"要它还是不要它"**。走到数组末尾，所有决定做完，path 就是其中一个子集。两种视角生成同一棵子集树，只是展开顺序不同。

### 完整代码（视角二：选/不选）

```go
package main

// LC78 视角二："选/不选"——每个元素二选一
func subsetsPick(nums []int) [][]int {
	res := [][]int{}
	path := []int{}

	var backtrack func(i int)
	backtrack = func(i int) {
		if i == len(nums) { // 每个元素都做过决定，收集
			tmp := make([]int, len(path))
			copy(tmp, path)
			res = append(res, tmp)
			return
		}
		backtrack(i + 1) // 不要 nums[i]

		path = append(path, nums[i]) // 要 nums[i]
		backtrack(i + 1)
		path = path[:len(path)-1]
	}
	backtrack(0)
	return res
}
```

### 双视角对比

|              | start 枚举视角           | 选/不选视角               |
|--------------|--------------------------|---------------------------|
| 树的形状     | 按位置分叉（矮胖）       | 按元素分叉（细长，2^n 叶）|
| 收集时机     | 每个节点都收集           | 只在叶子收集              |
| 推广到哪题   | LC39/77/40/90 组合系     | LC78/子集计数、分割系     |

### 复杂度

| 项目 | 复杂度    | 说明                          |
|------|-----------|-------------------------------|
| 时间 | O(n×2^n)  | 共 2^n 个子集，每个拷贝 O(n)  |
| 空间 | O(n)      | 递归深度（不计结果）          |

### 易错点

1. **进门就收集，不是只在叶子收集**——子集树没有"叶子"概念，每个节点都算答案。
2. `backtrack(i+1)` 写成 `backtrack(start+1)`：`i` 是当前选择位，`start` 是本层起点，混用会漏分支。
3. 照样要 copy，理由同 LC46。
4. 有重复元素的 LC90：排序后同层跳过重复值，和 LC47 一个套路。

### 🎤 口述模板

> "子集用回溯的 start 视角：每层从 start 往后枚举，天然保证只生成字典序组合、不会出现 [2,1] 这种重复。因为每个节点本身就是合法子集，进入函数先收集再扩展。另一种视角是对每个元素做选/不选的二叉决策，叶子收集，两者等价。时间 n 乘 2 的 n 次方。"

## 3｜LC17 电话号码的字母组合（中等）

**题干**：给数字串 `digits`（2-9），返回它能表示的所有字母组合（九宫格键盘：2→abc、3→def …）。

### 解题思路：每个数字一层，路径拼接

这题是回溯里最"纯净"的：**数字串的每个位置就是决策树的一层**，该层的"选择列表"就是对应键盘字母。比如 `"23"`：

```text
digits = "23"

          ""                ← 第 0 层：还没配对
    ┌──────┼──────┐
    a      b      c         ← 第 1 层：数字 2 的字母
   ┌┴┐    ┌┴┐    ┌┴┐
   d e f  d e f  d e f      ← 第 2 层：数字 3 的字母
   ad ae af bd be bf cd ce cf   ← 9 = 3×3 个叶子

mapping: 2→abc 3→def 4→ghi 5→jkl 6→mno 7→pqrs 8→tuv 9→wxyz
```

和 LC46 的区别：**不存在"用过就跳过"的问题**（不同层各配各的），连 used 都不用，只要一个 `i` 表示配到第几个数字。

### 完整代码（路径拼接）

```go
package main

// LC17 电话号码的字母组合：路径拼接
func letterCombinations(digits string) []string {
	if len(digits) == 0 { // 空串返回空列表，不是 [""]！
		return nil
	}
	// 数字 -> 字母表（0/1 没字母，占两个空位对齐下标）
	mapping := []string{"", "", "abc", "def", "ghi", "jkl",
		"mno", "pqrs", "tuv", "wxyz"}
	res := []string{}
	path := []byte{}

	var backtrack func(i int)
	backtrack = func(i int) {
		if i == len(digits) { // 每个数字都配好字母
			res = append(res, string(path))
			return
		}
		letters := mapping[digits[i]-'0'] // 本层的候选字母
		for j := 0; j < len(letters); j++ {
			path = append(path, letters[j]) // ① 选择一个字母
			backtrack(i + 1)                // ② 配下一个数字
			path = path[:len(path)-1]       // ③ 撤销
		}
	}
	backtrack(0)
	return res
}
```

### 复杂度

| 项目 | 复杂度    | 说明                                       |
|------|-----------|--------------------------------------------|
| 时间 | O(n×4^n)  | 最坏每个数字 4 个字母（7、9），叶子 4^n    |
| 空间 | O(n)      | 递归栈 + path（不计结果）                  |

### 易错点

1. **空串返回空列表**：`""` 的答案是 `[]` 不是 `[""]`，LC 专属边界坑。
2. `digits[i]-'0'` 把字符转数字；mapping 前两位空串占位（0/1 无字母），别错位。
3. 结果是 **组合不是排列**：`"23"` 输出顺序固定 ad→cf，不用排序去重。
4. 用 `[]byte` 当 path，收集时 `string(path)` 转一次即可，别用 `+=` 拼字符串（每次分配）。

### 🎤 口述模板

> "把数字串的每个位置当决策树的一层，层内枚举该数字键盘上的字母，选一个追加到 path、递归下一位、再弹出。下标走完收集一个组合。空串特判返回空列表。结果数是最坏 4 的 n 次方，时间就是它乘 n。"

## 4｜LC39 组合总和（中等）

**题干**：给**无重复**的正整数数组 `candidates` 和目标 `target`，找出所有和为 `target` 的组合。同一个数字可以**无限次重复选取**；`[2,2,3]` 与 `[2,3,2]` 算同一组合。

### 解题思路：start 不 +1 = 允许重复选

两个关键点，都是一行代码的事，但必须想明白：

1. **允许重复选**：递归传 `i` 而不是 `i+1`——下一层还能从当前这个数接着选（`[2,2,...]` 就这么来的）。同时 start 机制保证只往后看，`[2,3,2]` 这种乱序永远不会生成。
2. **剪枝**：先把 `candidates` 排序，循环里一旦 `candidates[i] > remain` 就 `break`——后面只会更大，整枝砍掉。剪枝前是"选了再发现超了"，剪枝后是"看一眼就知道别进去"。

```text
candidates=[2,3,6,7]（已排序），target=7

                    remain=7
          ├─选2 → remain=5
          │     ├─选2 → remain=3
          │     │     ├─选2 → remain=1 ✘（1<2 整枝 break）
          │     │     └─选3 → remain=0 ✓ 收 [2,2,3]
          │     └─选3 → remain=2 ... 3>2 break，无解
          ├─选3 → remain=4 → 选3 → 1 ✘ → 选... 无解
          └─选7 → remain=0 ✓ 收 [7]

答案：[2,2,3] 和 [7]
```

### 完整代码（排序 + break 剪枝）

```go
package main

import "sort"

// LC39 组合总和：允许重复选 → 递归传 i 不 +1
func combinationSum(candidates []int, target int) [][]int {
	sort.Ints(candidates) // 排序是剪枝前提：大了就能整枝 break
	res := [][]int{}
	path := []int{}

	var backtrack func(start, remain int)
	backtrack = func(start, remain int) {
		if remain == 0 { // 正好凑够 target
			tmp := make([]int, len(path))
			copy(tmp, path)
			res = append(res, tmp)
			return
		}
		for i := start; i < len(candidates); i++ {
			if candidates[i] > remain { // 排序后后面更大，整枝剪掉
				break
			}
			path = append(path, candidates[i])
			backtrack(i, remain-candidates[i]) // 传 i 不是 i+1：还能重复选
			path = path[:len(path)-1]
		}
	}
	backtrack(0, target)
	return res
}
```

### 复杂度

| 项目 | 复杂度             | 说明                                  |
|------|--------------------|---------------------------------------|
| 时间 | O(target/最小值)^n 量级（剪枝后远小） | 粗略上界，实际强依赖剪枝 |
| 空间 | O(target/最小值)    | 递归深度（不计结果）                  |

### 三个"组合"表兄弟对比

| 题目 | 能重复选？ | 递归传什么 | 额外剪枝          |
|------|-----------|-----------|-------------------|
| LC39 | ✔ 无限次  | `i`       | 排序 + break      |
| LC77 | ✘         | `i+1`     | 剩余不足 break    |
| LC40 | ✘（数组含重复） | `i+1` | 排序 + 同层跳重复值 |

### 易错点

1. **`backtrack(i, ...)` 传 i 不传 i+1**——传 i+1 就退化成 LC77（每个数只用一次），全错。
2. 剪枝必须**先排序**：不排序 `break` 不成立（后面可能有更小的），只能 `continue` 白扫。
3. 结束条件只有 `remain == 0`；`remain < 0` 的情况已被 break 剪掉，不用再判。
4. copy 收集老规矩；本题数组无重复所以不用同层去重（LC40 才要）。
5. 修改了入参 `candidates`（排序），面试提一句"不希望动入参就先 copy"。

### 🎤 口述模板

> "回溯：先排序。每层从 start 往后枚举候选，当前数比剩余目标还大就 break——排序保证了后面更大，整枝剪掉。选中就减 remain，递归时传 i 而不是 i+1，表示这个数还能重复选，这样天然生成非递减序列，不会出现乱序重复组合。remain 减到 0 就拷贝收集。"

## 5｜LC22 括号生成（中等）

**题干**：给 `n`，生成所有包含 `n` 对括号且**合法**的括号组合。

### 解题思路：左右计数两约束

"合法"拆开就两条，正好是两个可量化的约束：

1. **左括号最多 n 个**：`left < n` 时才能放 `(`；
2. **任意前缀右括号数 ≤ 左括号数**：`right < left` 时才能放 `)`——右边永远追着左边跑，序列就合法。

每层只有"放左还是放右"两个选择，各受一条约束管着，走到 `2n` 长度收集。

```text
n=2 的决策树（L=已放左括号数，R=已放右括号数）

                 "" (L0,R0)
              放(↙        ↘放) ✘ R<L 不成立，剪掉
            "(" (L1,R0)
          放(↙        ↘放)
      "((" (L2,R0)   "()" (L1,R1)
        ↘放)          放(✘ L=n 剪掉，只能放)
      "(()" (L2,R1)  "()(" (L2,R1)
        ↘放)            ↘放)
      "(())"✓         "()()"✓

两条约束把非法分支全部拦在半路，到叶子的必然合法
```

### 完整代码（左右计数两约束）

```go
package main

// LC22 括号生成：左右计数两约束
func generateParenthesis(n int) []string {
	res := []string{}
	path := []byte{}

	// left/right：已使用的左/右括号个数
	var backtrack func(left, right int)
	backtrack = func(left, right int) {
		if len(path) == 2*n { // n 对全放完，收集
			res = append(res, string(path))
			return
		}
		if left < n { // 约束一：左括号还有名额
			path = append(path, '(')
			backtrack(left+1, right)
			path = path[:len(path)-1]
		}
		if right < left { // 约束二：右括号必须紧追左括号
			path = append(path, ')')
			backtrack(left, right+1)
			path = path[:len(path)-1]
		}
	}
	backtrack(0, 0)
	return res
}
```

### 复杂度

| 项目 | 复杂度            | 说明                                    |
|------|-------------------|-----------------------------------------|
| 时间 | O(4^n / √n)       | 第 n 个卡特兰数的量级，剪枝后远小       |
| 空间 | O(n)              | 递归栈 + path（不计结果）               |

### 易错点

1. 两条约束别记反：`left < n` 管左、`right < left` 管右。写成 `right < n` 会生成 `")("` 这种非法串。
2. 结束条件是 `len(path) == 2*n`（n 对 = 2n 个字符），不是 n。
3. 这题**不需要** start/used——每层的选择就两个，由计数约束把关。
4. 结果数是卡特兰数：n=3 时 5 个、n=4 时 14 个，可以拿来当弱校验。

### 🎤 口述模板

> "回溯：用两个计数器。只要左括号还没用满 n 个就可以放左；只要右括号数小于已放左括号数就可以放右——第二条保证任意前缀右不超左，合法性在生成时就保证。路径长度到 2n 收集。结果数量是卡特兰数，4 的 n 次方除根号 n 量级。"

## 6｜LC79 单词搜索（中等）

**题干**：给 `m×n` 字符板 `board` 和单词 `word`，判断单词能否由**相邻**格子（上下左右）的字符连成——同一条路径里每个格子**最多用一次**。

### 解题思路：网格 DFS + 原地标记 + 撤销

把网格看成隐式图：格子是节点，四邻居是边，找一条路径恰好拼出 `word`。套路就是 LC200 沉岛的"升级版"——**区别在于这里必须撤销**：这条路径走不通，格子要还给下一条路径用，不能一沉了之。

```text
board:            word="ABCCED"
A B C E
S F C S           A(0,0)→B(0,1)→C(0,2)→C(1,2)
A D E E                              ↓E(2,2)→D(2,1) ✓

走一步：board[r][c] 改 '#' 占位（当前路径用过）
退一步：board[r][c] 改回原字符（撤销，还给别人）

对比 LC200：沉岛标记后【不恢复】；这里【必须恢复】
—— 这是"连通块计数"和"路径回溯"的分水岭
```

匹配到 `word[i]` 失败就返回 false，四个方向用 `||` 短路：一个方向成就不必再试。

### 完整代码（网格 DFS + 原地标记撤销）

```go
package main

// LC79 单词搜索：网格 DFS + 原地标记 + 撤销
func exist(board [][]byte, word string) bool {
	rows, cols := len(board), len(board[0])

	var dfs func(r, c, i int) bool // i：接下来要匹配 word 的第 i 个字符
	dfs = func(r, c, i int) bool {
		if i == len(word) { // 全部匹配完
			return true
		}
		if r < 0 || r >= rows || c < 0 || c >= cols || board[r][c] != word[i] {
			return false // 越界或字符对不上
		}
		board[r][c] = '#' // 原地标记：当前路径占用
		found := dfs(r+1, c, i+1) || dfs(r-1, c, i+1) ||
			dfs(r, c+1, i+1) || dfs(r, c-1, i+1) // 四方向短路
		board[r][c] = word[i] // 撤销：此路不通，格子还给后面的尝试
		return found
	}

	for r := 0; r < rows; r++ {
		for c := 0; c < cols; c++ {
			if dfs(r, c, 0) { // 每个格子都可能是起点
				return true
			}
		}
	}
	return false
}
```

### 与 LC212 呼应对比（图论组收官题，正好接上）

|              | LC79 单词搜索       | LC212 单词搜索 II                |
|--------------|---------------------|----------------------------------|
| 查几个词     | 1 个                | 一批词                           |
| 数据结构     | 直接在网格上匹配    | 所有词先建 Trie，沿 Trie 走      |
| 剪枝         | 字符对不上才返回    | 前缀不存在 → 整批单词一起剪掉    |
| 标记         | '#' 占用 + 撤销     | 同样 '#' + 撤销；命中后 word 置空防重复 |
| 时间         | O(mn·3^L)           | O(mn·3^L)，一次遍历服务全部词    |

一句话：**LC79 是 LC212 的地基，LC212 = LC79 的骨架 + Trie 导航**。

### 复杂度

| 项目 | 复杂度        | 说明                                  |
|------|---------------|---------------------------------------|
| 时间 | O(mn·3^L)     | mn 个起点，起点后每步至多 3 个新方向  |
| 空间 | O(L)          | 递归栈深度 = 单词长度（原地标记免 visited）|

### 易错点

1. **必须撤销标记**：不恢复的话第一条失败路径会把格子"污染"，后续尝试全错——这正是回溯的魂。
2. 先判 `i == len(word)` 再判越界，顺序反了会漏掉"最后一个字符刚好匹配完"的边界。
3. `board[r][c] = word[i]` 恢复时别写成恢复 `'#'` 或恢复错字符。
4. 超时急救：先统计 board 字符频次，word 里有字符不够用直接 false；或从 word 出现次数少的一头（首/尾字符）开始匹配。
5. `found` 用 `||` 连接天然短路，写成一个 if-else 链也行，但别忘任意方向成功就要 return true。

### 🎤 口述模板

> "在网格上做 DFS：从每个格子出发尝试匹配 word 的第 0 个字符，走之前把格子改成井号表示当前路径占用，四个方向递归匹配下一个字符，回来后把格子恢复——这就是回溯的撤销，保证失败路径不污染后续尝试。全部字符匹配完返回 true。复杂度 mn 乘 3 的单词长度次方。如果要匹配一批单词，就是 LC212：先建 Trie，沿 Trie 走，前缀不存在整枝剪掉。"

## 七、LC131 分割回文串（中等）

### 题干简述

字符串 s 按任意方式切成若干子串，**每段都是回文**，返回所有合法切法。`"aab" → [["a","a","b"],["aa","b"]]`。

### 解题思路：组合骨架换"选择列表"——start 不是选元素，是切一刀

把"分割"翻译成决策树：站在 start 位置，**下一刀切在哪**（end 从 start 到末尾逐个试），切出来的 `s[start:end+1]` 是回文才往下走：

```
s = "aab"
                      start=0
              ┌──────────┴──────────┐
          切 "a"✓                切 "aa"✓        （"aab"非回文，砍）
        start=1                 start=2
       ┌────┴────┐                │
   切"a"✓     切"ab"✗           切"b"✓ → 收 ["aa","b"] ✓
  start=2                          （start 越界=到底，收结果）
   切"b"✓ → 收 ["a","a","b"] ✓
```

和 LC39 组合总和完全同骨架，差别只有两点：选择从"选数"变成"切一刀"；**剪枝条件从"和超标"变成"切出来不是回文"**。回文判断可用双指针 O(n) 现判，进阶可预处理二维 `isPal[i][j]` 表（区间 DP，见 17_多维动态规划.md LC5）把判断降到 O(1)。

### 完整可编译代码

```go
package main

import "fmt"

func partition(s string) [][]string {
	var res [][]string
	var path []string
	var bt func(start int)
	bt = func(start int) {
		if start == len(s) { // 切到底，收一份
			tmp := make([]string, len(path))
			copy(tmp, path)
			res = append(res, tmp)
			return
		}
		for end := start; end < len(s); end++ {
			if !isPal(s, start, end) {
				continue // 不是回文，这一刀剪掉
			}
			path = append(path, s[start:end+1]) // 做选择：切这一刀
			bt(end + 1)                         // 递归：剩下的继续切
			path = path[:len(path)-1]           // 撤销：退刀
		}
	}
	bt(0)
	return res
}

func isPal(s string, l, r int) bool { // 双指针判回文
	for l < r {
		if s[l] != s[r] {
			return false
		}
		l++
		r--
	}
	return true
}

func main() {
	r := partition("aab")
	fmt.Println(len(r) == 2) // true: [["a","a","b"],["aa","b"]]
	fmt.Println(len(partition("a")) == 1)
}
```

### 复杂度

| 项 | 复杂度 | 说明 |
|----|--------|------|
| 时间 | O(n · 2ⁿ) | 最坏（全回文如 "aaaa"）每条缝切/不切两种选择 |
| 空间 | O(n) | 递归栈 + path（不计结果） |

### 易错点

1. 收集条件是 `start == len(s)`（切到底），不是 `path` 长度达标——每段长度不固定。
2. `end` 从 `start` 开始（单字符也是合法段），切片 `s[start:end+1]` 别写成 `s[start:end]`。
3. 预处理 isPal 表是进阶加分项：没预处理每刀 O(n) 判回文，预处理后 O(1)，呼应区间 DP。

### 🎤 口述模板

> "分割回文串就是组合题换皮：start 表示当前切到哪，end 从 start 往右试探下一刀的位置，切出来的段是回文才递归，start 走到串尾收集。剪枝就一条——不是回文整枝砍掉。进阶用区间 DP 预处理回文表把判断降到 O(1)。"

## 八、LC51 N 皇后（困难）

### 题干简目

n×n 棋盘放 n 个皇后，**任意两个不同行、不同列、不同对角线**，返回所有摆法。n=4 有 2 解。

### 解题思路：逐行放置的全排列骨架 + 三向冲突检查

按行放置（每行必放也只放一个），决策树的第 k 层 = 第 k 行选哪列——**本质还是全排列**，只是 used 从一个列数组扩成三向约束：

```
列冲突:   cols[col]                同列 ✓
主对角线: d1[row+col]              ↘ 方向，row+col 恒定
副对角线: d2[row-col+n]            ↙ 方向，row-col 恒定（+n 防负下标）

第 0 行放 col=1
 Q . . .
 . . Q ?   ← 第 1 行试 col=2：(0,1)(1,2) 在同一副对角线？1-0==2-1 ✓ 冲突，砍
 . . . ?   ← 试到合法列才往下……
```

撤销动作和排列完全一致：本行试完一列，三个标记数组全部复位。找到解的判定是 row == n（每行都放下了）。

### 完整可编译代码

```go
package main

import (
	"fmt"
	"strings"
)

func solveNQueens(n int) [][]string {
	var res [][]string
	cols := make([]bool, n)        // 列占用
	d1 := make([]bool, 2*n)        // 主对角线 row+col
	d2 := make([]bool, 2*n)        // 副对角线 row-col+n
	queens := make([]int, n)       // queens[row] = 该行放的列
	var bt func(row int)
	bt = func(row int) {
		if row == n { // n 行全放下，渲染棋盘
			board := make([]string, n)
			for r := 0; r < n; r++ {
				line := strings.Repeat(".", queens[r]) + "Q" + strings.Repeat(".", n-queens[r]-1)
				board[r] = line
			}
			res = append(res, board)
			return
		}
		for col := 0; col < n; col++ {
			if cols[col] || d1[row+col] || d2[row-col+n] {
				continue // 三向任一冲突，砍
			}
			cols[col], d1[row+col], d2[row-col+n] = true, true, true // 选择
			queens[row] = col
			bt(row + 1)                                               // 递归下一行
			cols[col], d1[row+col], d2[row-col+n] = false, false, false // 撤销
		}
	}
	bt(0)
	return res
}

func main() {
	fmt.Println(len(solveNQueens(4)) == 2)  // true
	fmt.Println(len(solveNQueens(1)) == 1)  // true
	fmt.Println(len(solveNQueens(8)) == 92) // true
}
```

### 复杂度

| 项 | 复杂度 | 说明 |
|----|--------|------|
| 时间 | O(n!) | 第一行 n 种、第二行最多 n−1 种……剪枝只是砍常数 |
| 空间 | O(n) | 递归栈 + 三个标记数组（不计结果） |

### 易错点

1. 对角线映射：主对角线 `row+col`、副对角线 `row−col`（可能为负，**+n 平移**）——这两个公式是本题唯一需要"背"的东西。
2. 按行放置保证行不冲突，所以行不用标记数组；按格 DFS 不分行列才是灾难写法。
3. 收集时渲染棋盘别忘了（题目要字符串棋盘），拷贝 path 的老规矩同样适用。

### 🎤 口述模板

> "N 皇后是全排列骨架的约束升级版：逐行放置，每层决策这一行放哪列，用三个布尔数组分别标记列、主对角线 row+col、副对角线 row−col+n 的占用，冲突就剪枝，回溯时三个标记同步复位。行号到 n 收集一份棋盘。O(n!)，对角线公式加 n 平移防负下标是唯一细节坑。"



```text
                    回溯三步：选择 → 递归 → 撤销
                              │
     ┌──────────┬─────────────┼───────────────┬─────────────┐
     ▼          ▼             ▼               ▼             ▼
  排列 LC46   子集 LC78     组合系 LC39     构造型 LC22    网格 LC79
  used 防重   start 只往后  传 i 允许重复   左右计数约束   '#'标记+撤销
     │          │          排序+break剪枝   两约束保合法   ──→ LC212

```
