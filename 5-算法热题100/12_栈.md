## 一、LC20 有效的括号（简单）

### 题干简述

字符串只含 `()[]{}`，判断是否**有效**：左括号必须以正确类型闭合，且顺序正确。`"()[]{}" → true`；`"(]" → false`。

### 解题思路：左括号进栈"欠债"，右括号来"还债"

嵌套结构的本质是**最近的左括号最先被关闭**——"最近相关性"，正是栈。

```
s = "{[()]}"

 读 { → 栈: {
 读 [ → 栈: { [
 读 ( → 栈: { [ (
 读 ) → 栈顶 ( 配对 ✓ 弹出 → 栈: { [
 读 ] → 栈顶 [ 配对 ✓ 弹出 → 栈: {
 读 } → 栈顶 { 配对 ✓ 弹出 → 栈: 空
扫完栈空 → true ✓

失败三态：右括号来时栈空（没人配）/ 栈顶不是同类 / 扫完栈非空（欠债没还）
```

实现细节：**栈里存左括号，遇到右括号查栈顶是否是"它的另一半"**。配对关系用哈希 `')'→'('` 反查，比一堆 if-else 干净。

### 完整可编译代码

```go
package main

import "fmt"

func isValid(s string) bool {
	pair := map[byte]byte{')': '(', ']': '[', '}': '{'} // 右→左 反查表
	stack := []byte{}
	for i := 0; i < len(s); i++ {
		c := s[i]
		if c == '(' || c == '[' || c == '{' {
			stack = append(stack, c) // 左括号欠债
		} else {
			if len(stack) == 0 || stack[len(stack)-1] != pair[c] {
				return false // 没人配 / 配错类型
			}
			stack = stack[:len(stack)-1] // 还债弹出
		}
	}
	return len(stack) == 0 // 欠债必须还清
}

func main() {
	fmt.Println(isValid("()[]{}") == true)  // true
	fmt.Println(isValid("(]") == false)     // true
	fmt.Println(isValid("([)]") == false)   // true
	fmt.Println(isValid("{[()]}") == true)  // true
}
```

### 复杂度

| 项 | 复杂度 |
|----|--------|
| 时间 | O(n) |
| 空间 | O(n)（最坏全是左括号） |

### 易错点

1. **三个失败态缺一不可**：右括号时栈空、栈顶类型不符、扫完栈非空。只查前两个会漏 `"(("`。
2. 奇数长度直接 return false 是常见小优化（先挡一层）。
3. 面试延伸：多种括号嵌套 + 优先级、或者表达式里的括号，同一套栈骨架不变。

### 🎤 口述模板

> "嵌套括号的本质是最近的左括号最先关闭，天然的栈结构。左括号进栈欠债，右括号查栈顶还债：栈空或类型不匹配立即 false，扫完还欠着（栈非空）也是 false。哈希表做右到左的反查配对。O(n) 时间，O(n) 空间。"

## 二、LC155 最小栈（中等）

### 题干简述

设计栈，支持 push / pop / top / **getMin**（取当前最小值），全部 **O(1)**。`push 5, push 2, push 4 → getMin=2；pop → getMin 仍 2；pop（2 出栈）→ getMin=5`。

### 解题思路：主栈旁边养一个"最小值快照栈"

难点：最小值被 pop 走后，怎么知道"剩下的里面谁最小"？——**每压一个元素，就记一份"当时的最小值快照"**：

```
主栈:     5   2   4   3
min栈:    5   2   2   2   ← 每层 = min(上层快照, 新元素)

pop 3 → 两栈同弹，min 栈露 2 → getMin=2 仍对
pop 4 → 同弹，露 2 ✓
pop 2 → 同弹，露 5 ✓ —— 2 的"时代"结束，快照自动回滚

本质：min 栈第 k 层 = 主栈前 k 个元素的最小值。
```

**变体（差值法）**：只存一个 min 变量 + 栈里存"新元素 − 当前 min"的差值——出栈时差值为负说明弹走的是最小值、可从差值反推出前一个 min。空间省一半，但可读性差，面试作为"我还知道更省的写法"讲出来即可。

### 完整可编译代码

```go
package main

import "fmt"

type MinStack struct {
	stack []int // 主栈
	mins  []int // 同步最小值快照栈
}

func Constructor() MinStack { return MinStack{} }

func (s *MinStack) Push(val int) {
	s.stack = append(s.stack, val)
	if len(s.mins) == 0 || val < s.mins[len(s.mins)-1] {
		s.mins = append(s.mins, val) // 新王登基
	} else {
		s.mins = append(s.mins, s.mins[len(s.mins)-1]) // 沿用旧王
	}
}

func (s *MinStack) Pop() {
	s.stack = s.stack[:len(s.stack)-1]
	s.mins = s.mins[:len(s.mins)-1] // 两栈同弹，快照回滚
}

func (s *MinStack) Top() int { return s.stack[len(s.stack)-1] }

func (s *MinStack) GetMin() int { return s.mins[len(s.mins)-1] }

func main() {
	s := Constructor()
	s.Push(5)
	s.Push(2)
	s.Push(4)
	fmt.Println(s.GetMin() == 2) // true
	s.Pop()
	fmt.Println(s.GetMin() == 2) // true
	s.Pop() // 2 出栈
	fmt.Println(s.GetMin() == 5) // true
}
```

### 复杂度

| 操作 | 复杂度 |
|------|--------|
| push / pop / top / getMin | 全 O(1) |
| 空间 | O(n)（辅助栈同长） |

### 易错点

1. min 栈**相等时也要压**（`val <= mins.top` 或沿用逻辑必须覆盖等于）：压两个 2，弹走一个后剩下的 2 还是最小——快照不能跳层。
2. 用"pop 时重扫一遍找新最小"是 O(n)，直接违反题意，别当解法提。
3. Go 切片模拟栈注意 append 与缩容同步，两栈长度永远相等是核心不变式。

### 🎤 口述模板

> "主栈旁边养一个同步的最小值快照栈：每 push 一个元素，快照栈压入'当时的历史最小'，相等也压；两栈永远同步弹。getMin 就是看快照栈顶，O(1)。本质是用 O(n) 空间把'每个时刻的最小值'全记下来，pop 掉最小值时快照自动回滚到上一个时代。我还知道差值法能省掉辅助栈，但可读性差一些。"

## 三、LC394 字符串解码（中等）

### 题干简述

编码规则 `k[encoded_string]` 表示括号内串重复 k 次，**可嵌套**。解码。`"3[a]cb" → "aaacb"`；`"3[a2[c]]" → "accaccacc"`。

### 解题思路：双栈——遇 `[` 存档，遇 `]` 读档

嵌套展开 = 套娃。遇到 `[` 就是"进入新的一层"，之前的进度要**存档**；遇到 `]` 就是"本层完工"，**读档**并把本层成果重复后接回去：

```
s = "3[a2[c]]"

两个栈：numStack（存档的倍数） strStack（存档的外层字符串）
cur = 当前层正在攒的串，num = 正在攒的倍数

读 3        → num=3
读 [        → 存档：numStack push 3, strStack push ""
             开新层：cur="", num=0
读 a        → cur="a"
读 2        → num=2
读 [        → 存档：numStack push 2, strStack push "a"
             开新层：cur="", num=0
读 c        → cur="c"
读 ]        → 读档：k=numStack 弹出 2, prev=strStack 弹出 "a"
             cur = prev + cur*2 = "a"+"cc" = "acc"
读 ]        → 读档：k=3, prev=""
             cur = "" + "acc"*3 = "accaccacc" ✓
```

三个状态一句话：**`cur` 攒本层、双栈存外层、数字可能多位数**（`12[a]` 要 `num = num*10 + d` 逐位攒）。

### 完整可编译代码

```go
package main

import (
	"fmt"
	"strings"
)

func decodeString(s string) string {
	numStack := []int{}    // 存档的倍数
	strStack := []string{} // 存档的外层串
	cur := ""              // 当前层正在攒的串
	num := 0               // 正在攒的倍数（可能多位）
	for i := 0; i < len(s); i++ {
		c := s[i]
		switch {
		case c >= '0' && c <= '9':
			num = num*10 + int(c-'0') // 多位数逐位攒
		case c == '[': // 存档开新层
			numStack = append(numStack, num)
			strStack = append(strStack, cur)
			num, cur = 0, ""
		case c == ']': // 本层完工读档
			k := numStack[len(numStack)-1]
			numStack = numStack[:len(numStack)-1]
			prev := strStack[len(strStack)-1]
			strStack = strStack[:len(strStack)-1]
			cur = prev + strings.Repeat(cur, k)
		default: // 普通字母
			cur += string(c)
		}
	}
	return cur
}

func main() {
	fmt.Println(decodeString("3[a]cb") == "aaacb")        // true
	fmt.Println(decodeString("3[a2[c]]") == "accaccacc")  // true
	fmt.Println(decodeString("12[ab]") == "abababababababababababab") // true
	fmt.Println(decodeString("abc") == "abc")             // true
}
```

### 复杂度

| 项 | 复杂度 | 说明 |
|----|--------|------|
| 时间 | O(结果串长度) | 输出本身可能远长于输入（k 乘出来） |
| 空间 | O(嵌套深度 + 结果) | 双栈 + 临时串 |

### 易错点

1. **多位数字**必须逐位攒 `num = num*10 + d`，只按个位数处理 `12[a]` 直接翻车。
2. 读档时 `cur = prev + repeat(cur, k)`——**prev 在前**，顺序接反输出整体倒挂。
3. 递归写法（遇 `[` 递归到 `]`）同样可行，但迭代双栈版状态全显式，面试讲起来更稳。

### 🎤 口述模板

> "嵌套展开就是存档读档：遇左括号把外层进度压进双栈——数字栈存倍数、字符串栈存前文，然后开新层；遇右括号读档，把本层成果按倍数展开接回前文。数字要按多位数逐位攒。时间复杂度按输出长度算，因为 k 可以把串乘得很长。"

## 四、LC739 每日温度（中等）

### 题干简述

每日温度数组，回答**还要等几天才升温**；等不到填 0。`[73,74,75,71,69,72,76,73] → [1,1,4,2,1,1,0,0]`。

### 解题思路：单调栈——"还没等到答案的日期"在栈里排队

暴力对每天向后扫是 O(n²)。换个视角：**让每个元素去找"它前面的、比它小的、还在等答案的日期"**：

```
temperatures = [73, 74, 75, 71, 69, 72, 76, 73]
栈里存下标，栈内温度保持从底到顶递减（等升温的队伍）

i=0 73 → 栈空，进栈            栈: [0(73)]
i=1 74 → 74>73！0 号等到了
        ans[0]=1-0=1，弹 0；栈空，1 进栈   栈: [1(74)]
i=2 75 → 75>74，ans[1]=1，弹 1；2 进栈    栈: [2(75)]
i=3 71 → 71<75 不升温，3 进栈            栈: [2,3]
i=4 69 → 69<71，4 进栈                   栈: [2,3,4]
i=5 72 → 72>69 → ans[4]=1 弹 4
        72>71 → ans[3]=2 弹 3
        72<75 停，5 进栈                  栈: [2,5]
i=6 76 → 76>72 → ans[5]=1 弹 5
        76>75 → ans[2]=4 弹 2
        6 进栈                            栈: [6]
i=7 73 → 73<76，7 进栈                   栈: [6,7]
结束，栈里剩下的（6、7）永远没等到 → ans=0 ✓
```

**为什么是 O(n)**：每个下标最多进栈一次、出栈一次，总操作 2n——这就是单调栈的摊还分析，面试必说。

**单调栈模板口诀**：找"下一个更大"→ 递减栈，遇更大就结算弹出；找"下一个更小"→ 递增栈。同族题：LC42 接雨水（见 02_双指针.md）、LC84 柱状图最大矩形、LC496 下一个更大元素。

### 完整可编译代码

```go
package main

import "fmt"

func dailyTemperatures(T []int) []int {
	ans := make([]int, len(T))
	stack := []int{} // 存下标；对应温度从底到顶递减
	for i, t := range T {
		for len(stack) > 0 && t > T[stack[len(stack)-1]] {
			j := stack[len(stack)-1] // j 号等到了升温
			stack = stack[:len(stack)-1]
			ans[j] = i - j // 等了几天
		}
		stack = append(stack, i) // 自己开始等
	}
	return ans // 栈里剩的默认 0（永远没等到）
}

func main() {
	got := dailyTemperatures([]int{73, 74, 75, 71, 69, 72, 76, 73})
	want := []int{1, 1, 4, 2, 1, 1, 0, 0}
	ok := true
	for i := range want {
		if got[i] != want[i] {
			ok = false
		}
	}
	fmt.Println(ok) // true
	fmt.Println(dailyTemperatures([]int{30, 40, 50, 60})[3] == 0) // true
}
```

### 复杂度

| 项 | 复杂度 | 说明 |
|----|--------|------|
| 时间 | O(n) | 每个下标进出栈各一次（摊还） |
| 空间 | O(n) | 最坏单调递减序列全员在栈 |

### 易错点

1. **栈里存下标不是温度**——答案要算天数差，温度没这信息。
2. 弹出条件 `t > T[栈顶]` 严格大于：相等不算升温（按题意同温不触发）。
3. 摊还 O(n) 的解释要会说：总入栈 n 次、总出栈 ≤ n 次，嵌套 while 不是 O(n²) 的原因。

### 🎤 口述模板

> "找下一个更大元素用单调递减栈：栈里存还没等到答案的下标，新温度来了就把栈顶所有比它小的逐个结算——弹出并记天数差。每个下标进栈出栈各一次，摊还 O(n)。接雨水、柱状图最大矩形、下一个更大元素全是这个模板，区别只在栈内单调方向和结算时怎么算面积。"
