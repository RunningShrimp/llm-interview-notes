## 一、堆的三句话心智模型

1. **堆 = 一个"永远记得最值"的数组**。你只管往里塞数，它保证堆顶永远是当前最小（小顶堆）或最大（大顶堆）的那个。
2. **堆顶取值 O(1)，插入/弹出 O(log n)**。比每次全排序 O(n log n) 便宜得多，也比维护有序数组（插入挪位 O(n)）划算。
3. **Top K = 一场容量为 K 的"淘汰赛"**：求前 K 大 → 用**小顶堆**，堆顶是门槛，比门槛大才进堆，进堆就踢掉门槛；求前 K 小反过来。

```
小顶堆：逻辑上是二叉树，物理上就是数组

          1  ← 堆顶，全场最小，"淘汰赛门槛"
        /   \
       3     2
      / \
     5   4

数组存储：[1, 3, 2, 5, 4]
下标关系：节点 i 的孩子是 2i+1、2i+2，父亲是 (i-1)/2
```

## 二、container/heap 模板（先背这个再做题）

Go 标准库 `container/heap` 只提供上浮/下沉的调度，**数据怎么存、怎么比大小要自己实现 `heap.Interface`**，共 5 个方法（大家习惯叫"四件套模板"）：

```go
type IntHeap []int

func (h IntHeap) Len() int            { return len(h) }
func (h IntHeap) Less(i, j int) bool  { return h[i] < h[j] } // < 小顶堆；> 大顶堆
func (h IntHeap) Swap(i, j int)       { h[i], h[j] = h[j], h[i] }
func (h *IntHeap) Push(x interface{}) { *h = append(*h, x.(int)) }
func (h *IntHeap) Pop() interface{} {
	old := *h
	n := len(old)
	x := old[n-1] // Pop 约定返回最后一个元素，heap 包负责"堆顶换末尾再下沉"
	*h = old[:n-1]
	return x
}
```

三个使用要点（全是踩过的坑）：

- `Push/Pop` 必须**指针接收者** `*h`，否则改的是切片副本，堆长度根本不变（能编译，必写错）。
- 业务代码只调 `heap.Init / heap.Push / heap.Pop`，**不要**直接 `h.Push(...)`——后者不做上浮。
- `heap.Pop` 返回 `interface{}`，要 `.(int)` 断言拿值。

## 四、LC215 数组中的第K个最大元素（中等）

### 题干简述

给无序数组 `nums` 和整数 `k`，返回其中**第 k 个最大的元素**（注意：按名次算，重复元素也占名次，不是第 k 个不同的数）。例：`[3,2,1,5,6,4], k=2 → 5`。

### 解题思路（直觉引导）

第一反应：降序排序取第 k 个，O(n log n)。面试官追问："能不能不全排？"

想一下：我们只关心"最大的 k 个数组成的圈子"里**最弱的那个**。最弱的 = 门槛 = **小顶堆堆顶**：

1. 维护容量 k 的小顶堆，堆顶 = 圈内最弱；
2. 新数 > 堆顶 → 踢掉堆顶、新数进圈；否则直接无视；
3. 扫完数组，堆顶即第 k 大。

```
[3,2,1,5,6,4]，k=2，堆的演化：
放 3      → [3]
放 2      → [2,3]              堆顶 2
放 1      → 长度 3 > k → 弹 1 → [2,3]
放 5 > 2  → 弹 2，进 5 → [3,5]  堆顶 3
放 6 > 3  → 弹 3，进 6 → [5,6]  堆顶 5
放 4 < 5  → 无视
堆顶 5 = 第 2 大 ✓
```

### 解法一：小顶堆（完整可编译）

```go
package main

import (
	"container/heap"
	"fmt"
)

// IntHeap 小顶堆：求"第 K 大"的守门员堆
type IntHeap []int

func (h IntHeap) Len() int            { return len(h) }
func (h IntHeap) Less(i, j int) bool  { return h[i] < h[j] }
func (h IntHeap) Swap(i, j int)       { h[i], h[j] = h[j], h[i] }
func (h *IntHeap) Push(x interface{}) { *h = append(*h, x.(int)) }
func (h *IntHeap) Pop() interface{} {
	old := *h
	n := len(old)
	x := old[n-1]
	*h = old[:n-1]
	return x
}

func findKthLargest(nums []int, k int) int {
	h := &IntHeap{}
	heap.Init(h)
	for _, v := range nums {
		heap.Push(h, v)
		if h.Len() > k {
			heap.Pop(h) // 超容就弹最小，堆里始终是"前 k 大"
		}
	}
	return (*h)[0] // 堆顶 = 第 k 大
}

func main() {
	fmt.Println(findKthLargest([]int{3, 2, 1, 5, 6, 4}, 2) == 5)          // true
	fmt.Println(findKthLargest([]int{3, 2, 3, 1, 2, 4, 5, 5, 6}, 4) == 4) // true
}
```

### 解法二：快速选择（平均 O(n)，被追问时掏出来）

直觉：快排 partition 每趟能把一个数**永久就位**到下标 p。第 k 大 = 升序下标 `n-k`——p 命中直接返回，没命中就只往答案所在的那一半继续，**另一半整个扔掉**。n + n/2 + n/4 + … ≈ 2n = O(n)。

```go
package main

import "fmt"

func findKthLargest(nums []int, k int) int {
	target := len(nums) - k // 第 k 大 ↔ 升序下标 n-k
	l, r := 0, len(nums)-1
	for l <= r {
		p := partition(nums, l, r)
		switch {
		case p == target:
			return nums[p]
		case p < target:
			l = p + 1
		default:
			r = p - 1
		}
	}
	return -1 // 不会走到
}

func partition(nums []int, l, r int) int {
	pivot := nums[r]
	i := l
	for j := l; j < r; j++ {
		if nums[j] < pivot {
			nums[i], nums[j] = nums[j], nums[i]
			i++
		}
	}
	nums[i], nums[r] = nums[r], nums[i]
	return i // nums[i] 就位：左边 < 它，右边 >= 它
}

func main() {
	fmt.Println(findKthLargest([]int{3, 2, 1, 5, 6, 4}, 2) == 5) // true
}
```

### 解法对比

| 方案 | 时间 | 空间 | 备注 |
|------|------|------|------|
| 小顶堆 size=k | O(n log k) | O(k) | **面试首选**；数据流/海量数据（内存放不下全集）唯一解 |
| 快速选择 | 平均 O(n)，最坏 O(n²) | O(1) 原地 | 静态数组 + 面试官逼问 O(n) 时 |
| 全排序 | O(n log n) | O(1)~O(n) | 30 秒保底答案 |

海量扩展：10 亿数找 Top 100 → 分片各自 Top 100 → 归并，堆仍是主角。

### 复杂度（解法一）

| 项 | 复杂度 | 说明 |
|----|--------|------|
| 时间 | O(n log k) | n 次入堆，每次 O(log k) |
| 空间 | O(k) | 堆最多 k 个元素 |

### 易错点

1. **方向反了**：第 k 大用**小**顶堆（堆顶=门槛），第 k 小才用大顶堆。
2. `heap.Pop(h)` 忘了 `.(int)` 断言；对值类型调用 Push 长度不变。
3. "第 k 个最大，重复计数"——别去重！`[3,2,3,1,2,4,5,5,6], k=4` 答案是 4 不是 3。

### 🎤 口述模板

> "维护容量 k 的小顶堆当淘汰赛擂台：比堆顶大就踢掉堆顶进来，比堆顶小直接走。扫完堆里正好是最大 k 个，堆顶就是答案，O(n log k)。海量数据流场景只能用它；静态数组可快速选择到平均 O(n)，但最坏退化 O(n²)，工程上我选堆，稳。"

## 五、LC347 前K个高频元素（中等）

### 题干简述

给整数数组 `nums` 和整数 `k`，返回**出现频率前 k 高**的元素，任意顺序。例：`[1,1,1,2,2,3], k=2 → [1,2]`。

### 解题思路（直觉引导）

两步走，没有悬念：

1. **数频次**：一遍哈希 `map[值]频次`，O(n)。
2. **频次 Top K**：LC215 同款淘汰赛，只是比较键从"数值"换成"频次"——堆元素升级成 `(值, 频次)` 二元组，这就是 Pair 结构体的由来。

```
[1,1,1,2,2,3] 计数 → {1:3, 2:2, 3:1}，k=2
（map 遍历顺序随机，不影响结果，按 1,2,3 演示）
进 (1,3) → 堆 [(1,3)]
进 (2,2) → 堆 [(2,2),(1,3)]        堆顶是频次最小的 (2,2)
进 (3,1) → 长度 3 > 2 → 弹堆顶 (3,1)
最终堆 [(2,2),(1,3)] → 答案 {1,2} ✓
```

### 完整可编译代码

```go
package main

import (
	"container/heap"
	"fmt"
)

// Pair 堆里存"值 + 频次"
type Pair struct {
	val int
	cnt int
}

// PairHeap 按频次比大小的小顶堆（模板同 IntHeap，只改 Less 和类型）
type PairHeap []Pair

func (h PairHeap) Len() int            { return len(h) }
func (h PairHeap) Less(i, j int) bool  { return h[i].cnt < h[j].cnt } // 按频次小顶
func (h PairHeap) Swap(i, j int)       { h[i], h[j] = h[j], h[i] }
func (h *PairHeap) Push(x interface{}) { *h = append(*h, x.(Pair)) }
func (h *PairHeap) Pop() interface{} {
	old := *h
	n := len(old)
	x := old[n-1]
	*h = old[:n-1]
	return x
}

func topKFrequent(nums []int, k int) []int {
	cnt := make(map[int]int)
	for _, v := range nums {
		cnt[v]++
	}
	h := &PairHeap{}
	heap.Init(h)
	for val, c := range cnt {
		heap.Push(h, Pair{val: val, cnt: c})
		if h.Len() > k {
			heap.Pop(h) // 踢掉频次最低的
		}
	}
	res := make([]int, 0, k)
	for _, p := range *h {
		res = append(res, p.val)
	}
	return res
}

func main() {
	got := topKFrequent([]int{1, 1, 1, 2, 2, 3}, 2)
	fmt.Println(len(got) == 2 && contains(got, 1) && contains(got, 2)) // true
}

func contains(arr []int, x int) bool {
	for _, v := range arr {
		if v == x {
			return true
		}
	}
	return false
}
```

### 桶排序彩蛋（加分项）

频次范围天然是 `[1, n]`，可按频次建桶 `bucket[频次] = []值`，从高频桶往低收集，O(n) 不用堆。但海量流式 Top K 还是堆的主场——桶要 O(n) 空间且得先知道 n。

| 解法 | 时间 | 空间 | 备注 |
|------|------|------|------|
| 哈希 + 小顶堆 | O(n log k) | O(n) | 通用，流式场景主角 |
| 哈希 + 桶排序 | O(n) | O(n) | 静态数组最快 |

### 复杂度

| 项 | 复杂度 | 说明 |
|----|--------|------|
| 时间 | O(n log k) | 计数 O(n) + m 个不同数入堆 O(m log k) |
| 空间 | O(n) | 哈希 O(m) + 堆 O(k) |

### 易错点

1. `Less` 写成比较 `val` 而非 `cnt`——淘汰赛变成"值最小 Top K"。
2. `heap.Pop` 断言 `.(Pair)`，别照抄 `.(int)`。
3. map 遍历随机 → 输出顺序不稳定，自测 assert 先排序再比。

### 🎤 口述模板

> "两步：哈希数频次，LC215 同款 size=k 小顶堆淘汰赛，比较键换成频次，堆元素升级成 Pair。O(n log k)。追问更快就用频次桶排序 O(n)，但流式海量场景还得是堆。"

## 六、LC295 数据流的中位数（困难）

### 题干简述

设计 `MedianFinder`：`AddNum(num)` 加数、`FindMedian()` 返回当前全部数的中位数。数据流可能几十万个数，查询高频。`[1,2] → 1.5`；`[1,2,3] → 2`。

### 解题思路：为什么是"两个堆"？

中位数 = 排序后切一刀，**左半最大 + 右半最小**（奇数取左半最大）。

暴力：每次查询排一次序 O(n log n)，或有序数组插入 O(n)——数据流一长全爆。

关键洞察：**求中位数不需要全排序，只要刀口处两个数：左半最大、右半最小。**"随时取最值"正是堆的看家本领：

- **左半放大顶堆** `left`：堆顶 = 左半最大；
- **右半放小顶堆** `right`：堆顶 = 右半最小；
- 约定长度差 ≤ 1，且**左半允许多 1**（奇数时答案直接取左堆顶，不用判断哪边多）。

```
已排序视角：  [1, 3, 5, 7] | [9, 11, 13, 15]
               ↑左半(大顶堆)   ↑右半(小顶堆)
               堆顶=7          堆顶=9
中位数 = (7+9)/2 = 8

不变量（写代码前先背下来）：
  ① len(left) == len(right) 或 len(left) == len(right)+1
  ② left 全部元素 ≤ right 全部元素
```

AddNum 调度（先想放哪边，再调平衡）：

1. `left` 空 或 `num <= left 堆顶` → 进 left，否则进 right；
2. left 比 right 多超过 1 → 搬 left 堆顶去 right；
3. right 比 left 多 → 搬 right 堆顶回 left。

### 完整可编译代码（MedianFinder 全量）

```go
package main

import (
	"container/heap"
	"fmt"
)

// MaxHeap 左半边：大顶堆，堆顶 = 左半最大
type MaxHeap []int

func (h MaxHeap) Len() int            { return len(h) }
func (h MaxHeap) Less(i, j int) bool  { return h[i] > h[j] } // > 大顶
func (h MaxHeap) Swap(i, j int)       { h[i], h[j] = h[j], h[i] }
func (h *MaxHeap) Push(x interface{}) { *h = append(*h, x.(int)) }
func (h *MaxHeap) Pop() interface{} {
	old := *h
	n := len(old)
	x := old[n-1]
	*h = old[:n-1]
	return x
}

// MinHeap 右半边：小顶堆，堆顶 = 右半最小
type MinHeap []int

func (h MinHeap) Len() int            { return len(h) }
func (h MinHeap) Less(i, j int) bool  { return h[i] < h[j] } // < 小顶
func (h MinHeap) Swap(i, j int)       { h[i], h[j] = h[j], h[i] }
func (h *MinHeap) Push(x interface{}) { *h = append(*h, x.(int)) }
func (h *MinHeap) Pop() interface{} {
	old := *h
	n := len(old)
	x := old[n-1]
	*h = old[:n-1]
	return x
}

// MedianFinder 用两个堆"夹住"中位数刀口
type MedianFinder struct {
	left  MaxHeap
	right MinHeap
}

func Constructor() MedianFinder {
	return MedianFinder{left: MaxHeap{}, right: MinHeap{}}
}

func (mf *MedianFinder) AddNum(num int) {
	if mf.left.Len() == 0 || num <= mf.left[0] {
		heap.Push(&mf.left, num) // 属于左半边
	} else {
		heap.Push(&mf.right, num) // 属于右半边
	}
	// 平衡：left 最多比 right 多 1
	if mf.left.Len() > mf.right.Len()+1 {
		heap.Push(&mf.right, heap.Pop(&mf.left).(int))
	} else if mf.right.Len() > mf.left.Len() {
		heap.Push(&mf.left, heap.Pop(&mf.right).(int))
	}
}

func (mf *MedianFinder) FindMedian() float64 {
	if mf.left.Len() > mf.right.Len() { // 奇数个：约定左半多 1
		return float64(mf.left[0])
	}
	return float64(mf.left[0]+mf.right[0]) / 2 // 偶数个：两堆顶平均
}

func main() {
	mf := Constructor()
	mf.AddNum(1)
	mf.AddNum(2)
	fmt.Println(mf.FindMedian() == 1.5) // true
	mf.AddNum(3)
	fmt.Println(mf.FindMedian() == 2) // true
	mf.AddNum(4)
	fmt.Println(mf.FindMedian() == 2.5) // true
}
```

### 复杂度

| 操作 | 时间 | 空间 |
|------|------|------|
| AddNum | O(log n) | 总 O(n) |
| FindMedian | O(1) | — |

### 易错点

1. **方向放反**：左半必须**大顶堆**（要看左半最大），右半小顶堆。
2. 平衡条件写成 `>=` 或搬的方向反了，长度差超过 1 就乱。
3. `heap.Pop(&mf.left).(int)` 忘断言；空堆取 `mf.left[0]` 越界（本题调度不会，变体要防）。

### 🎤 口述模板

> "中位数只要刀口两边的数：左半最大、右半最小——一个堆管一个。左大顶右小顶，长度差 ≤1 且左允许多 1。插入先按'和左堆顶比大小'选边，再搬一次堆顶调平衡，O(log n)；查询看两个堆顶 O(1)。这是'对顶堆'原型，滑动窗口中位数（LC480）是它加延迟删除的扩展。"
