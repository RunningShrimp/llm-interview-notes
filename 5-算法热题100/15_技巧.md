## 一、LC136 只出现一次的数字（简单）

### 题干简述

非空数组里**恰好一个元素出现一次，其余都出现两次**，找出那个一次的。要求线性时间 + 常数空间。`[4,1,2,1,2] → 4`。

### 解题思路（直觉引导）

哈希表数频次？O(n) 时间但 O(n) 空间，不满足"常数空间"。

异或三条律：

1. `a ^ a = 0`（自己消自己）
2. `a ^ 0 = a`（和 0 异或不亏不赚）
3. 交换律 + 结合律（顺序随便换）

把全数组异或一遍：成对的互相抵消变 0，最后只剩落单的——**全员大乱斗，配对同归于尽，活下来的就是答案**。

```
4 ^ 1 ^ 2 ^ 1 ^ 2
= 4 ^ (1^1) ^ (2^2)   ← 交换律重排，配对挪一起
= 4 ^ 0 ^ 0
= 4  ✓
```

### 完整可编译代码

```go
package main

import "fmt"

func singleNumber(nums []int) int {
	x := 0
	for _, v := range nums {
		x ^= v // 配对的迟早互相抵消，落单的活到最后
	}
	return x
}

func main() {
	fmt.Println(singleNumber([]int{4, 1, 2, 1, 2}) == 4) // true
	fmt.Println(singleNumber([]int{2, 2, 1}) == 1)       // true
}
```

### 复杂度

| 项 | 复杂度 |
|----|--------|
| 时间 | O(n) |
| 空间 | O(1) |

### 易错点

1. 前提是"其余恰好出现两次"——出现三次是 LC137（按位统计 mod 3），别硬套异或。
2. 初始值用 0（`0^a=a`），从下标 0 直接累异或，最不容易写错。

### 🎤 口述模板

> "异或满足 a^a=0、a^0=a，加交换结合律，把整个数组累异或一遍，成对的全部同归于尽，剩下的就是只出现一次的那个。O(n) 时间 O(1) 空间。"

## 二、LC169 多数元素（简单）

### 题干简述

找**出现次数大于 ⌊n/2⌋ 的元素**（题目保证存在）。`[2,2,1,1,1,2,2] → 2`。进阶：线性时间 + 常数空间。

### 解题思路：摩尔投票 = 打仗（抵消 + 验证两个 Phase）

把每个数值当一个**阵营**，不同阵营士兵相遇就**一对一同归于尽**：

- `count == 0`：场上没有现任候选人，当前元素 v 上位，count=1；
- `v == candidate`：友军，count++；
- `v != candidate`：敌军，同归于尽 count--。

```
[2,2,1,1,1,2,2]
 2 → count=1   (2 上位)
 2 → count=2   (友军)
 1 → count=1   (一个 2 和一个 1 同归于尽)
 1 → count=0   (又一对耗掉，场上清空)
 1 → count=1   (候选人换成 1)
 2 → count=0   (2 把 1 拖死，又清空)
 2 → count=1   (2 上位)
最终候选人 = 2 ✓

为什么赢的必然是多数：阵营 2 有 4 人，其他全部才 3 人，
哪怕每次抵消都拉一个 2 陪葬，2 还剩 4-3=1 个活着。
```

标准摩尔投票两个 Phase：

- **抵消 Phase**：如上，选出最后站着的候选人；
- **验证 Phase**：再扫一遍数候选人的真实次数，确认 > n/2。

LC169 **保证**多数存在，验证可省；不保证时（LC229 求 ≥ n/3 的多数）必须验证。

### 完整可编译代码

```go
package main

import "fmt"

func majorityElement(nums []int) int {
	candidate, count := 0, 0
	for _, v := range nums {
		if count == 0 { // 场上无候选人，v 上位
			candidate = v
		}
		if v == candidate {
			count++ // 友军 +1
		} else {
			count-- // 敌军同归于尽 -1
		}
	}
	// 题目保证多数存在，省略验证 Phase；
	// 不保证时需再扫一遍确认真实次数 > n/2
	return candidate
}

func main() {
	fmt.Println(majorityElement([]int{2, 2, 1, 1, 1, 2, 2}) == 2) // true
	fmt.Println(majorityElement([]int{3, 2, 3}) == 3)             // true
}
```

### 复杂度

| 项 | 复杂度 |
|----|--------|
| 时间 | O(n)（加验证 Phase 也是 O(n)） |
| 空间 | O(1) |

### 易错点

1. `count == 0` 时**先换候选人再判友军/敌军**（当前 v 自己 count++），顺序反了会把 v 也抵消掉。
2. 面试主动提"不保证存在时要第二遍验证"——这是摩尔投票完整形态，多数人只知道一半。
3. 别和 LC229（≥ n/3，最多两个候选人）搞混：那题要两对 candidate/count。

### 🎤 口述模板

> "摩尔投票：不同元素一对一抵消，相同元素攒票，count 归零就换候选人。多数元素超过一半，其他所有数加起来也抵消不完它，最后站着的必然是多数。O(n) O(1)；若题目不保证存在，再扫一遍验证。"

## 三、LC75 颜色分类（中等）

### 题干简述

数组里只有 0/1/2 三种值，**原地**排成 `000...111...222`，要求**一次扫描 + 常数空间**（禁用库排序）。`[2,0,2,1,1,0] → [0,0,1,1,2,2]`。经典名：荷兰国旗问题。

### 解题思路：三指针分区

目标把数组切三段，三个指针守边界：

- `p0`：下一个 0 应放的位置（0 区右边界+1）；
- `i`：当前扫描位置（1 区自然长大）；
- `p2`：下一个 2 应放的位置（2 区左边界-1）。

```
[2, 0, 2, 1, 1, 0]   初始 p0=0, i=0, p2=5

分区不变式（循环每一刻都成立）：
  [0, p0)  全是 0
  [p0, i)  全是 1
  (p2, n)  全是 2
  [i, p2]  待处理
```

遇到 0：换到 p0，`p0++ i++`；遇到 1：`i++`；遇到 2：换到 p2，`p2--`，**i 不动**（从 p2 换过来的可能是 0/1/2，还没检查过）。

### 完整可编译代码

```go
package main

import "fmt"

func sortColors(nums []int) {
	p0, i, p2 := 0, 0, len(nums)-1
	for i <= p2 {
		switch nums[i] {
		case 0:
			nums[p0], nums[i] = nums[i], nums[p0]
			p0++
			i++ // 从 p0 换来的只可能是 1（早扫描过了），放心前进
		case 2:
			nums[p2], nums[i] = nums[i], nums[p2]
			p2--
			// i 不动！从 p2 换来的还没检查
		default: // 1 留原地，1 区自然长大
			i++
		}
	}
}

func main() {
	nums := []int{2, 0, 2, 1, 1, 0}
	sortColors(nums)
	fmt.Println(fmt.Sprint(nums) == "[0 0 1 1 2 2]") // true
	nums2 := []int{2, 0, 1}
	sortColors(nums2)
	fmt.Println(fmt.Sprint(nums2) == "[0 1 2]") // true
}
```

### 复杂度

| 项 | 复杂度 | 说明 |
|----|--------|------|
| 时间 | O(n) | 每个元素最多被换两次 |
| 空间 | O(1) | 原地三指针 |

### 易错点（本题细节浓度最高）

1. **case 2 之后 i 不动**——换过来的元素来自未扫描区，必须重审；case 0 之后 i 可以动，因为换来的来自已扫描区，只可能是 1。
2. 循环条件 `i <= p2`，写错会把排好的 2 又翻出来。
3. 计数排序（数个数再覆写）两遍扫描也能过，但面试官点名"一遍扫描"时要上三指针。

### 🎤 口述模板

> "荷兰国旗三指针：p0 守 0 区右边界，p2 守 2 区左边界，i 扫描。遇 0 换到 p0 双进，遇 2 换到 p2 但 i 原地重审（换来的没检查过），遇 1 直接过。一次扫描 O(n) O(1)，关键细节是 case 2 后 i 不能前进。"

## 四、LC31 下一个排列（中等）

### 题干简述

把整数数组改成**字典序刚好大一号**的下一个排列；已是最大排列则翻回最小。**原地**修改。`[1,2,3] → [1,3,2]`；`[3,2,1] → [1,2,3]`。

### 解题思路：四步法（拨密码锁的直觉）

想变大：**尽量动靠右的位，动完还要尽量小**。

```
[1, 5, 8, 4, 7, 6, 5, 3, 1]
                 ↑
从右往左找第一对升序对 (4,7)：i 指向 4
（i 右边全是降序 = 已是局部最大，动它们没用）

再从右往左找第一个 > 4 的数：5（刚好更大的那个）
交换 → [1, 5, 8, 5, | 7, 6, 4, 3, 1]
此时 i 右边仍是降序（最大排法），要变"刚好大一号"
→ 反转后缀成升序（最小排法）
→ [1, 5, 8, 5, 1, 3, 4, 6, 7] ✓
```

四步：

1. 从右往左找第一对 `nums[i] < nums[i+1]`（找不到 = 整体降序 = 最大排列，直接跳第 4 步反转全表）；
2. 从右往左找第一个 `nums[j] > nums[i]`（右边降序，从右第一个恰好是"刚好更大"）；
3. 交换 i、j；
4. 反转 i 之后的后缀（降序→升序，从最大变最小）。

### 完整可编译代码

```go
package main

import "fmt"

func nextPermutation(nums []int) {
	n := len(nums)
	// ① 从右找第一对升序对
	i := n - 2
	for i >= 0 && nums[i] >= nums[i+1] {
		i--
	}
	// ②③ 找刚好更大的数并交换（i<0 = 整体降序，跳过）
	if i >= 0 {
		j := n - 1
		for nums[j] <= nums[i] {
			j--
		}
		nums[i], nums[j] = nums[j], nums[i]
	}
	// ④ 反转后缀（交换后必是降序，反转即最小）
	for l, r := i+1, n-1; l < r; l, r = l+1, r-1 {
		nums[l], nums[r] = nums[r], nums[l]
	}
}

func main() {
	a := []int{1, 2, 3}
	nextPermutation(a)
	fmt.Println(fmt.Sprint(a) == "[1 3 2]") // true
	b := []int{3, 2, 1}
	nextPermutation(b)
	fmt.Println(fmt.Sprint(b) == "[1 2 3]") // true
	c := []int{1, 5, 8, 4, 7, 6, 5, 3, 1}
	nextPermutation(c)
	fmt.Println(fmt.Sprint(c) == "[1 5 8 5 1 3 4 6 7]") // true
}
```

### 复杂度

| 项 | 复杂度 | 说明 |
|----|--------|------|
| 时间 | O(n) | 两次从右扫描 + 一次反转 |
| 空间 | O(1) | 原地 |

### 易错点

1. 步骤①比较写成 `>`（找降序对）——方向反了求出"上一个排列"。
2. 步骤②要找"**刚好更大**"（右边降序时从右第一个恰好就是），不是随便一个更大的。
3. 交换后**后缀仍是降序**（可证明），直接反转即可不用再排序；i<0 时也要走反转（整体回最小）。

### 🎤 口述模板

> "下一个排列四步：从右找第一对升序对定住要动的位；从右找刚好比它大的数交换；反转后缀变升序。直觉是拨号锁：尽量动右边的位，动完把尾巴调成最小。找不到升序对说明已是最大，整体反转回最小。O(n) 原地，C++ 的 next_permutation 就是这个算法。"

## 五、LC287 寻找重复数（中等）

### 题干简述

`n+1` 个整数，每个都在 `[1, n]` 范围内，**至少一个重复**（可能重复多次），要求**不修改数组、O(1) 额外空间**找出重复数。`[1,3,4,2,2] → 2`。

### 解题思路：Floyd 判圈，值域当 next 指针

视角转换：把 `i → nums[i]` 看成一条边，数组变成一张"函数图"。值都在 `[1,n]` 而下标 0..n——**从 0 出发不断 `next = nums[next]` 必然走进环**（鸽笼：n+1 个位置只有 1..n 种去处），而**环的入口就是重复数**（两个下标存了同一个值 v → 两条边都指向节点 v）。

```
nums = [1, 3, 4, 2, 2]
下标:   0  1  2  3  4
边:     0→1  1→3  2→4  3→2  4→2

  0 → 1 → 3 → 2 → 4
            ↑______|      环：2 → 4 → 2，入口 = 下标 2
                          值 2 出现在下标 3、4 → 两条边汇入节点 2
                          重复数 = 环入口 = 2 ✓

和 LC142 环形链表 II 完全同构：
  slow 一步: slow = nums[slow]
  fast 两步: fast = nums[nums[fast]]
```

两阶段（数学推导见 LC142，记住结论）：

- **阶段一**：快慢指针找环内相遇点；
- **阶段二**：一个指针回起点 0，两指针同速走，**再相遇 = 环入口 = 重复数**。

（数学：起点到入口 a 步、环长 L、相遇点距入口 b，快指针路程是慢的两倍 → `a = (k−1)L + (L−b)` → 从起点走 a 步与从相遇点绕到入口同时到达。）

起点为什么选 0：值域 `[1,n]` 保证所有 `nums[i] ≥ 1`，**没有任何边指向下标 0**，所以 0 必在环外，从它出发才谈得上"找入口"。这个细节能讲清很加分。

### 完整可编译代码

```go
package main

import "fmt"

func findDuplicate(nums []int) int {
	// 阶段一：快慢指针找环内相遇点
	slow, fast := nums[0], nums[nums[0]]
	for slow != fast {
		slow = nums[slow]         // 一步
		fast = nums[nums[fast]]   // 两步
	}
	// 阶段二：一个回起点，同速前进，再相遇 = 环入口 = 重复数
	slow = 0
	for slow != fast {
		slow = nums[slow]
		fast = nums[fast]
	}
	return slow
}

func main() {
	fmt.Println(findDuplicate([]int{1, 3, 4, 2, 2}) == 2) // true
	fmt.Println(findDuplicate([]int{3, 1, 3, 4, 2}) == 3) // true
	fmt.Println(findDuplicate([]int{1, 1}) == 1)          // true
}
```

### 解法对比

| 解法 | 时间 | 空间 | 改数组？ | 备注 |
|------|------|------|----------|------|
| Floyd 判圈 | O(n) | O(1) | 否 ✓ | 满足全部限制，面试最优 |
| 二分值域 | O(n log n) | O(1) | 否 | 统计 ≤mid 个数二分缩值域，好想但慢一档 |
| 哈希集合 | O(n) | O(n) | 否 | 空间超标，当铺垫说 |
| 排序/原地归位 | O(n log n)/O(n) | O(1) | **是 ✗** | 题目不许改数组 |

### 复杂度

| 项 | 复杂度 |
|----|--------|
| 时间 | O(n)（两阶段各最多走几圈） |
| 空间 | O(1) |

### 易错点

1. 快慢指针初始化 `slow=nums[0]、fast=nums[nums[0]]`（等价都从 0 先走一步/两步），保证 do-while 语义。
2. 阶段二 slow 要回**起点 0**，不是回 nums[0]。
3. 本题禁改数组，所以 LC41 那套原地归位不能用——同是"找重复/缺失"，限制条件决定解法。

### 🎤 口述模板

> "把 i→nums[i] 当链表 next 指针：n+1 个位置、值域 [1,n]，鸽笼保证从 0 出发必进环，环入口就是重复数。剩下完全复用 LC142 的 Floyd 判圈：快慢找相遇点，再一个回起点同速走，再相遇即入口。O(n) 时间 O(1) 空间且不改数组。"

## 六、LC41 缺失的第一个正数（中等）

> 原地哈希一族的祖师爷，同族详解见 `05_普通数组.md`（本文是技巧组视角精简复现，六要素齐全）。

### 题干简述

未排序整数数组（可含负数和 0），返回**没有出现的最小正整数**。要求 O(n) 时间 + O(1) 空间。`[1,2,0] → 3`；`[3,4,-1,1] → 2`；`[7,8,9,11,12] → 1`。

### 解题思路：原地归位，"值 v 放到下标 v−1"

关键观察：**答案必在 `[1, n+1]` 内**（n 个数最多覆盖 1..n，全齐才是 n+1）。所以：

- 负数、0、大于 n 的数都是**废物**，无视；
- 有用的数 v（1 ≤ v ≤ n）**应该待在下标 v−1**，即 `nums[v-1] == v`（值即下标，哈希函数免了——这就是"原地哈希"）。

归位后**第一个 `nums[i] != i+1` 的位置 i，答案就是 i+1**；全归位则答案 n+1。

```
[3, 4, -1, 1]   n=4，目标布局 [1, 2, 3, 4]
i=0: 3 应去下标 2   → [-1, 4, 3, 1]
     -1 废物，停
i=1: 4 应去下标 3   → [-1, 1, 3, 4]
     换来的 1 应去下标 0 → [1, -1, 3, 4]   ← while 不是 if！
     -1 废物，停
i=2: 3 已在位（nums[2]=3）跳过
i=3: 4 已在位，跳过
终扫：nums[1] ≠ 2 → 答案 2 ✓
```

**为什么 while 不是 if**：换过来的数可能也要归位，得连环换，直到废物/越界/已在位才停。

**这一族的族谱**（同一个"归位"模板）：

| 题 | 归位后答案 | 备注 |
|----|------------|------|
| LC41 缺失第一个正数 | 第一个 `nums[i]≠i+1` 的 i+1 | 本文 |
| LC448 找消失的数字 | 所有 `nums[i]≠i+1` 的 i+1 | 收集所有 |
| LC442 找重复的数据 | 所有 `nums[i]≠i+1` 的 `nums[i]` | 反向收 |
| LC287 寻找重复数 | 禁改数组 → 只能 Floyd 判圈 | 见上文 |

### 完整可编译代码

```go
package main

import "fmt"

func firstMissingPositive(nums []int) int {
	n := len(nums)
	for i := 0; i < n; i++ {
		// 连环归位：v 在 [1,n] 且 v 的位置上不是 v（防死循环）
		for nums[i] >= 1 && nums[i] <= n && nums[nums[i]-1] != nums[i] {
			nums[i], nums[nums[i]-1] = nums[nums[i]-1], nums[i]
		}
	}
	for i := 0; i < n; i++ { // 第一个不在位的
		if nums[i] != i+1 {
			return i + 1
		}
	}
	return n + 1 // 1..n 全在位
}

func main() {
	fmt.Println(firstMissingPositive([]int{1, 2, 0}) == 3)         // true
	fmt.Println(firstMissingPositive([]int{3, 4, -1, 1}) == 2)     // true
	fmt.Println(firstMissingPositive([]int{7, 8, 9, 11, 12}) == 1) // true
	fmt.Println(firstMissingPositive([]int{1}) == 2)               // true
}
```

### 复杂度

| 项 | 复杂度 | 说明 |
|----|--------|------|
| 时间 | O(n) | 每次交换至少让一个数永久归位，总交换 ≤ n（摊还分析） |
| 空间 | O(1) | 原地交换 |

### 易错点

1. 归位循环必须是 **while**，写 if 会有数没归位；条件 `nums[nums[i]-1] != nums[i]` 防两个相同值互换死循环（如两个 1）。
2. Go 多重赋值 `nums[i], nums[nums[i]-1] = nums[nums[i]-1], nums[i]` **先求右边再赋值**，顺序天然正确；拆成两行临时变量顺序不对就废（经典坑）。
3. 答案上界 n+1 别忘（`[1,2,3] → 4`）；负数/0/大数一律忽略，别试图清理。

### 🎤 口述模板

> "答案只可能在 1 到 n+1 之间，所以把范围内每个数 v 原地换到下标 v−1（while 连环换，换来的也要归位），废物数直接跳过。归位后第一个 nums[i] 不等于 i+1 的位置，i+1 就是答案。每次交换至少归位一个数，摊还 O(n)，空间 O(1)。LC448、442 全是同款模板。"
