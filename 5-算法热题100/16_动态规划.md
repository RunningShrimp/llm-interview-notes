## 二、DP 解题五步法

写任何 DP 题之前,先在心里把这五步过一遍,基本不会翻车:

```
┌─────────────────────────────────────────────────────┐
│ ① 定义状态   dp[i] 到底代表什么?(最关键的一步!)    │
│ ② 转移方程   dp[i] 怎么由前面的状态推出来?           │
│ ③ 初始化     边界在哪?dp[0] 给什么值?               │
│ ④ 遍历顺序   谁先算谁后算?有没有依赖方向?           │
│ ⑤ 空间优化   能不能用几个变量滚动?能不能压维?       │
└─────────────────────────────────────────────────────┘
```

| 步骤 | 一句话口诀 | 典型翻车现场 |
|------|-----------|--------------|
| ① 定义状态 | "前 i 个"还是"以 i 结尾"? | 定义成前缀,推导却按结尾 |
| ② 转移方程 | 最后一步从哪来? | 漏分支(LC152 的负数) |
| ③ 初始化 | 边界值别拍脑袋 | 求"最少"却初始化成 0 |
| ④ 遍历顺序 | 依赖谁,谁先算 | 01 背包一维必须倒序 |
| ⑤ 空间优化 | 只看上一行 / 上两个变量 | 压维后覆盖了还没用的值 |

其中第 ① 步是灵魂:同一个问题,状态定义不同,转移方程天差地别。本篇 LC32"最长有效括号"就是最好的例子——把状态定义成"**以 i 结尾**的最长有效长度",推导瞬间就顺了。

## 三、LC70 爬楼梯(简单)

> 假设你正在爬楼梯,需要 `n` 阶才能到楼顶。每次可以爬 1 或 2 个台阶,问有多少种不同的方法?

### 3.1 解题思路

先别想什么高大上的名词,手玩最朴素的情况:n=1 有 1 种、n=2 有 2 种、n=3 有 3 种、n=4 有 5 种……斐波那契的味道出来了。

发现规律了吗?**想到达第 n 阶,最后一步只有两种可能**:

```
                       ┌── 最后一步爬 1 阶 → 之前在 n-1 阶,有 f(n-1) 种
到第 n 阶的方法 f(n) ──┤
                       └── 最后一步爬 2 阶 → 之前在 n-2 阶,有 f(n-2) 种
```

```
f(n) = f(n-1) + f(n-2)   ← 两类方法不重不漏,直接相加
```

这不就是斐波那契嘛!按五步法过一遍:

| 步骤 | 本题答案 |
|------|----------|
| ① 状态 | `f(i)` = 爬到第 i 阶的方法数 |
| ② 转移 | `f(i) = f(i-1) + f(i-2)` |
| ③ 初始化 | `f(1)=1, f(2)=2` |
| ④ 顺序 | 从小到大(i = 3 → n) |
| ⑤ 优化 | 只依赖前两个值 → 两个变量滚动,O(n) → O(1) 空间 |

### 3.2 代码

```go
package main

import "fmt"

func climbStairs(n int) int {
	if n <= 2 {
		return n // f(1)=1, f(2)=2,顺手处理边界
	}
	prev, curr := 1, 2 // 滚动变量:prev=f(i-2), curr=f(i-1)
	for i := 3; i <= n; i++ {
		prev, curr = curr, prev+curr // 整体前进一格:f(i)=f(i-1)+f(i-2)
	}
	return curr
}

func main() {
	fmt.Println(climbStairs(2) == 2) // 1+1 / 2
	fmt.Println(climbStairs(3) == 3) // 1+1+1 / 1+2 / 2+1
}
```

### 3.3 复杂度

| 维度 | 分析 |
|------|------|
| 时间 | O(n),一次线性递推 |
| 空间 | O(1),滚动变量替代整个 dp 数组 |

### 3.4 易错点

- 边界 n=1、n=2 直接返回,别让循环从 i=3 启动时引用到负数下标
- 题目 n ≤ 45,`int` 够用;n 再大一截就会溢出,得换大数(面试提一嘴加分)

### 🎤 口述模板

> "爬到第 n 阶的最后一步,要么跨 1 阶要么跨 2 阶,两类不重不漏,方法数相加,就是斐波那契递推。因为每个状态只依赖前两个状态,我用两个变量滚动,空间压到 O(1)。"

## 四、LC118 杨辉三角(简单)

> 给定行数 `numRows`,生成"杨辉三角"的前 numRows 行。

### 4.1 解题思路

杨辉三角咱们中学就见过:

```
        1
       1 1
      1 2 1
     1 3 3 1
    1 4 6 4 1
```

规律肉眼可见:**每一行的内部元素 = 上一行左右两数之和**;每行两端永远是 1。放进 DP 框架:

| 步骤 | 本题答案 |
|------|----------|
| ① 状态 | `res[i][j]` = 第 i 行第 j 个元素 |
| ② 转移 | `res[i][j] = res[i-1][j-1] + res[i-1][j]`(仅内部元素) |
| ③ 初始化 | 每行首尾 `res[i][0] = res[i][i] = 1` |
| ④ 顺序 | 行从上到下,列从左到右 |

### 4.2 代码

```go
package main

import "fmt"

func generate(numRows int) [][]int {
	res := make([][]int, numRows)
	for i := 0; i < numRows; i++ {
		res[i] = make([]int, i+1)   // 第 i 行有 i+1 个元素
		res[i][0], res[i][i] = 1, 1 // 两端永远是 1
		for j := 1; j < i; j++ {    // 只推内部元素
			res[i][j] = res[i-1][j-1] + res[i-1][j] // 上一行左右之和
		}
	}
	return res
}

func main() {
	r1 := generate(5)
	fmt.Println(len(r1) == 5 && r1[4][2] == 6) // 第5行 [1,4,6,4,1]
	r2 := generate(1)
	fmt.Println(len(r2) == 1 && r2[0][0] == 1) // 只有 [1]
}
```

### 4.3 复杂度

| 维度 | 分析 |
|------|------|
| 时间 | O(numRows²),元素总量就是这个量级 |
| 空间 | O(1) 额外空间(返回值不计) |

### 4.4 易错点

- 内层循环范围是 `j ∈ [1, i-1]`,把两端也算进去会越界
- Go 的二维切片要逐行 make,不初始化行直接赋值会 panic(nil 切片)

### 🎤 口述模板

> "杨辉三角每行首尾是 1,内部每个数等于上一行左右两数之和,逐行递推生成即可,时间和空间都是 O(n²),其中空间主要是返回值本身。"

## 五、LC198 打家劫舍(中等)

> 你是小偷,沿街有一排房屋,每间有现金 `nums[i]`,**相邻两间不能同时偷**,求能偷到的最高金额。

### 5.1 解题思路

关键提问:站在第 i 间房门口,你只有两个选择——**偷 or 不偷**:

```
              ┌─ 偷 nums[i] → 第 i-1 间绝对不能碰 → 金额 = f(i-2) + nums[i]
对第 i 间房 ──┤
              └─ 不偷       → 前面随便            → 金额 = f(i-1)
```

两种选择取较大者:

```
f(i) = max( f(i-1),  f(i-2) + nums[i] )
```

看,爬楼梯的"加法"在这里变成了"取 max"——这就是**决策型 DP**:每一步在若干选择里挑最优。

| 步骤 | 本题答案 |
|------|----------|
| ① 状态 | `f(i)` = 考虑前 i+1 间房能偷到的最高金额 |
| ② 转移 | `f(i) = max(f(i-1), f(i-2)+nums[i])` |
| ③ 初始化 | `f(0)=nums[0]`,`f(1)=max(nums[0], nums[1])` |
| ④ 顺序 | 从左到右 |
| ⑤ 优化 | 同爬楼梯,两个变量滚动 |

### 5.2 代码

```go
package main

import "fmt"

func rob(nums []int) int {
	n := len(nums)
	if n == 1 {
		return nums[0]
	}
	prev2, prev1 := nums[0], max(nums[0], nums[1]) // f(0), f(1)
	for i := 2; i < n; i++ {
		// 不偷 i:继承 prev1;偷 i:prev2 + nums[i]
		prev2, prev1 = prev1, max(prev1, prev2+nums[i])
	}
	return prev1
}

// Go 1.21 之前 max 不是内建函数,手写一个保平安
func max(a, b int) int {
	if a > b {
		return a
	}
	return b
}

func main() {
	fmt.Println(rob([]int{1, 2, 3, 1}) == 4)     // 偷 1 号和 3 号:1+3
	fmt.Println(rob([]int{2, 7, 9, 3, 1}) == 12) // 偷 2+9+1
}
```

### 5.3 复杂度

| 维度 | 分析 |
|------|------|
| 时间 | O(n) |
| 空间 | O(1),滚动变量 |

### 5.4 易错点

- 初始化 `f(1)` 必须是 `max(nums[0], nums[1])`,直接写 nums[1] 会错(比如 [2,1])

### 🎤 口述模板

> "每间房只有偷和不偷两种选择:偷就加上 i-2 的最优解,不偷就继承 i-1 的最优解,取 max。转移只依赖前两个状态,两个变量滚动,空间 O(1)。"

## 六、LC279 完全平方数(中等)

> 给你整数 n,返回和为 n 的完全平方数(1、4、9、16…)的**最少数量**。

### 6.1 解题思路

先把问题翻译成背包语言:物品集合是 {1, 4, 9, 16, ...},每种**无限个**,问装满容量 n 最少要几件——这不就是**完全背包**吗!(平方数 = 物品,体积 = 平方数本身,求最少件数)

对每个容量 i,枚举最后放入的平方数 j*j(比如凑 12:枚举 1、4、9,最终 4+4+4 三件最优):

```
dp[i] = min( dp[i - j*j] + 1 ),  其中 j*j <= i
```

| 步骤 | 本题答案 |
|------|----------|
| ① 状态 | `dp[i]` = 凑出 i 的最少平方数个数 |
| ② 转移 | `dp[i] = min(dp[i-j*j]+1)`,j 从 1 到 √i |
| ③ 初始化 | `dp[0]=0`(凑 0 要 0 个),其余设为 +∞ |
| ④ 顺序 | 容量从小到大 |

### 6.2 代码

```go
package main

import (
	"fmt"
	"math"
)

func numSquares(n int) int {
	dp := make([]int, n+1)
	for i := 1; i <= n; i++ {
		dp[i] = math.MaxInt32 // "还没凑出来"的无穷大占位
		for j := 1; j*j <= i; j++ {
			if dp[i-j*j]+1 < dp[i] { // 放入一个 j*j,看能否更少
				dp[i] = dp[i-j*j] + 1
			}
		}
	}
	return dp[n]
}

func main() {
	fmt.Println(numSquares(12) == 3) // 4+4+4
	fmt.Println(numSquares(13) == 2) // 4+9
}
```

### 6.3 复杂度

| 维度 | 分析 |
|------|------|
| 时间 | O(n·√n),外层容量、内层枚举平方数 |
| 空间 | O(n) |

### 6.4 易错点

- "求最少"类 DP 必须初始化成 +∞,初始化成 0 的话 min 永远取不对
- 内层边界是 `j*j <= i`,写错会算出负下标
- `dp[0]=0` 是整个递推的地基,别漏

### 🎤 口述模板

> "把完全平方数看成无限量的物品,凑满容量 n 求最少件数,就是完全背包。转移时枚举最后一个放入的平方数,dp[i] 取 dp[i 减去该平方数] 加一的最小值,初始化无穷大、dp[0] 为 0。"

## 七、LC322 零钱兑换(中等)

> 给你硬币面额数组 coins 和总金额 amount,每种硬币**无限个**,计算凑成 amount 所需的**最少硬币个数**;凑不出返回 -1。

### 7.1 解题思路

和 LC279 几乎是双胞胎:把平方数换成任意面额而已:

```
dp[i] = min( dp[i - c] + 1 ),  c 取遍所有面额且 c <= i
```

**灵魂拷问:能不能贪心,每次都拿最大面额?** 面试官最爱挖这个坑,拿 coins={1,3,4}、amount=6 举例:

```
贪心:  4 + 1 + 1   →  3 枚   ✗
最优:  3 + 3       →  2 枚   ✓
```

贪心"先拿大的"会一头锁死在次优解上——因为**大面额不一定能参与最优组合**。DP 把所有可能都算一遍取最小,不迷信任何单一策略,所以稳。

| 步骤 | 本题答案 |
|------|----------|
| ① 状态 | `dp[i]` = 凑出金额 i 的最少硬币数 |
| ② 转移 | `dp[i] = min(dp[i-c]+1)`,c ∈ coins 且 c ≤ i |
| ③ 初始化 | `dp[0]=0`,其余 +∞(注意不是 -1!) |
| ④ 顺序 | 金额从小到大 |
| ⑤ 优化 | 无限硬币 → 一维正序即可(对比 01 背包的倒序) |

### 7.2 代码

```go
package main

import "fmt"

func coinChange(coins []int, amount int) int {
	const inf = 100001 // 比 amount 上限(10^4)大即可
	dp := make([]int, amount+1)
	for i := 1; i <= amount; i++ {
		dp[i] = inf // "凑不出"的占位
	}
	for i := 1; i <= amount; i++ {
		for _, c := range coins {
			if c <= i && dp[i-c]+1 < dp[i] {
				dp[i] = dp[i-c] + 1 // 最后一枚用面额 c
			}
		}
	}
	if dp[amount] == inf {
		return -1 // 推到头都没凑出来
	}
	return dp[amount]
}

func main() {
	fmt.Println(coinChange([]int{1, 2, 5}, 11) == 3) // 5+5+1
	fmt.Println(coinChange([]int{2}, 3) == -1)       // 全偶数凑不出奇数
}
```

### 7.3 复杂度

| 维度 | 分析 |
|------|------|
| 时间 | O(amount × len(coins)) |
| 空间 | O(amount) |

### 7.4 易错点

- "求最少"初始化是**无穷大**,只有 dp[0] 是 0
- 面额可能比 amount 还大,内层必须判 `c <= i`;结尾靠 dp 是否仍为 inf 返回 -1

### 🎤 口述模板

> "典型完全背包求最少件数:dp[i] 表示金额 i 的最少硬币数,枚举最后一枚硬币的面额转移取最小,初始化无穷大。贪心不可行——面额 1、3、4 凑 6,贪心拿 4 要三枚,而 3+3 只要两枚。"

## 八、LC139 单词拆分(中等)

> 给你字符串 s 和单词字典 wordDict,判断 s 能否拆成一个或多个字典单词(单词可重复使用)。

### 8.1 解题思路

字符串 DP 第一课:**把"在哪里切"变成"最后一段从哪开始"**。

定义 `dp[i]` = s 的前 i 个字符(s[0:i])能否拆成字典单词。最后一段是谁?枚举起点 j:

```
        s[0 ........ j)   +   s[j ........ i)
        └── dp[j] 真? ──┘     └── 在字典里? ──┘
                │                      │
                └── 两个都成立 → dp[i] = true ──┘
```

注意 s[j:i] 的字典查询要用 set(Go 的 map)做到 O(1),否则每段线性扫字典,复杂度直接爆炸。

| 步骤 | 本题答案 |
|------|----------|
| ① 状态 | `dp[i]` = 前 i 个字符能否拆成字典单词 |
| ② 转移 | `dp[i] = OR(dp[j] && dict[s[j:i]])`,j ∈ [0, i) |
| ③ 初始化 | `dp[0] = true`(空串天然可拆,是递推地基) |
| ④ 顺序 | i 从小到大,j 在 i 内部枚举 |
| ⑤ 优化 | 按字典最长单词长度剪枝 j 的下界 |

### 8.2 代码

```go
package main

import "fmt"

func wordBreak(s string, wordDict []string) bool {
	dict := make(map[string]bool, len(wordDict))
	maxLen := 0
	for _, w := range wordDict {
		dict[w] = true // set 化,O(1) 查询
		if len(w) > maxLen {
			maxLen = len(w)
		}
	}
	n := len(s)
	dp := make([]bool, n+1)
	dp[0] = true // 空串:递推的地基
	for i := 1; i <= n; i++ {
		for j := 0; j < i; j++ {
			if i-j > maxLen {
				continue // 剪枝:单词不可能这么长
			}
			if dp[j] && dict[s[j:i]] { // 前缀可拆 && 最后一段在字典
				dp[i] = true
				break // 找到一种拆法就够了
			}
		}
	}
	return dp[n]
}

func main() {
	fmt.Println(wordBreak("leetcode", []string{"leet", "code"}) == true)
	fmt.Println(wordBreak("catsandog", []string{"cats", "dog", "sand", "and", "cat"}) == false)
}
```

### 8.3 复杂度

| 维度 | 分析 |
|------|------|
| 时间 | O(n²) 量级(剪枝后远小于),子串哈希另计 O(n) |
| 空间 | O(n + 字典总字符数) |

### 8.4 易错点

- dp 开 n+1,`dp[0]=true` 是"空串"边界,漏了整盘皆 false
- `s[j:i]` 每次生成子串拷贝,数据量大可换字典树(面试提一嘴加分)

### 🎤 口述模板

> "定义 dp[i] 表示前 i 个字符能否拆成字典单词,枚举最后一段的起点 j,dp[i] 为真当且仅当 dp[j] 为真且 j 到 i 这段在字典里。字典做成哈希 set 加速查询,整体 O(n²)。"

## 九、LC300 最长递增子序列(中等)

> 给你整数数组 nums,求其中**最长严格递增子序列**(LIS)的长度。子序列可以不连续。

### 9.1 解题思路

#### 解法一:O(n²) 经典 DP

直觉引导:想知道"以 nums[i] 结尾的 LIS 有多长",就看它**能接在谁的后面**:

```
nums = [10, 9, 2, 5, 3, 7]
                  ↑
   以 7 结尾能接谁?比 7 小的:2 / 5 / 3
   dp[i] = max(dp(以2结尾), dp(以5结尾), dp(以3结尾)) + 1

dp[i] = max(dp[j] + 1),  其中 j < i 且 nums[j] < nums[i]
```

| 步骤 | 本题答案 |
|------|----------|
| ① 状态 | `dp[i]` = **以 nums[i] 结尾**的 LIS 长度 |
| ② 转移 | `dp[i] = max(dp[j]+1)`,j < i 且 nums[j] < nums[i] |
| ③ 初始化 | 全部 1(自己单拎一个) |
| ④ 顺序 | i 从左到右,j 扫 [0, i) |
| ⑤ 答案 | **max(dp[])**,不是 dp[n-1]!(LIS 不一定以末尾收场) |

#### 解法二:贪心 + 二分,O(n log n)

维护 tails:tails[k] = "长度为 k+1 的递增子序列的**最小可能结尾**"。每来一个数 x,二分找第一个 ≥ x 的位置替换;都比 x 小就追加:

```
x=10 → 追加 [10]  x=9 → 替换 [9]  x=2 → 替换 [2]
x=5  → 追加 [2,5] x=3 → 替换 [2,3]
x=7  → 追加 [2,3,7]  → LIS 长度 = 3
```

结尾越小,后面越容易接得更长——这就是"贪心";tails 始终有序,所以能二分。

| 解法 | 时间 | 空间 | 说明 |
|------|------|------|------|
| O(n²) DP | O(n²) | O(n) | 好想好写,能还原方案,n ≤ 10^4 稳过 |
| 贪心+二分 | O(n log n) | O(n) | n 到 10^5 必备;tails 不一定是真实 LIS |

### 9.2 代码

```go
package main

import "fmt"

// 解法一:O(n^2) DP
func lengthOfLIS(nums []int) int {
	n := len(nums)
	dp := make([]int, n)
	for i := range dp {
		dp[i] = 1 // 自己就是长度 1 的子序列
	}
	ans := 1
	for i := 1; i < n; i++ {
		for j := 0; j < i; j++ {
			if nums[j] < nums[i] && dp[j]+1 > dp[i] {
				dp[i] = dp[j] + 1 // 接在 j 后面更长
			}
		}
		if dp[i] > ans {
			ans = dp[i] // 全局最大,不是 dp[n-1]
		}
	}
	return ans
}

// 解法二:贪心 + 二分,O(n log n)
func lengthOfLISBin(nums []int) int {
	var tails []int
	for _, x := range nums {
		lo, hi := 0, len(tails)
		for lo < hi { // 二分找第一个 >= x 的位置
			mid := (lo + hi) / 2
			if tails[mid] < x {
				lo = mid + 1
			} else {
				hi = mid
			}
		}
		if lo == len(tails) {
			tails = append(tails, x) // x 比谁都大,LIS 变长
		} else {
			tails[lo] = x // 换掉,让结尾更小更有潜力
		}
	}
	return len(tails)
}

func main() {
	fmt.Println(lengthOfLIS([]int{10, 9, 2, 5, 3, 7, 101, 18}) == 4)
	fmt.Println(lengthOfLISBin([]int{0, 1, 0, 3, 2, 3}) == 4)
}
```

### 9.3 易错点

- 答案是 `max(dp)`,**不是 dp[n-1]**——LIS 不一定以最后一个元素结尾
- 状态是"以 i 结尾",和"前 i 个里的 LIS"是两码事,别混着推
- 严格递增用 `<`,别手滑写成 `<=`

### 🎤 口述模板

> "我定义 dp[i] 为以 nums[i] 结尾的最长递增子序列长度,枚举所有值更小的前驱 j 接上去取最大,O(n²)。数据量大就用贪心加二分:维护每个长度对应的最小结尾,来一个数就二分替换或追加,降到 n log n,注意 tails 本身不是真实的 LIS。"

## 十、LC152 乘积最大子数组(中等)

> 给你整数数组 nums,找出乘积最大的**非空连续子数组**,返回该乘积。

### 10.1 解题思路

先回忆 LC53 最大子数组**和**:加法里正数只会越加越大,维护一个"以 i 结尾的最大和"就够了。

乘积的坑在于:**负数 × 负数 = 正数**!眼下很小的负数,乘上后面的负数瞬间起飞:

```
nums = [2, 3, -2, 4]  → 最大乘积 2×3 = 6
nums = [-2, 3, -4]    → (-2)×3=-6 很小,再乘 -4 = 24,直接封神!
```

所以只记"最大"不够,得**同时维护以 i 结尾的最大值和最小值**:

```
x ≥ 0:新 max = max(x, 老max×x)   新 min = min(x, 老min×x)
x < 0:先把 max / min 交换身份,再做上面同样的运算
```

| 步骤 | 本题答案 |
|------|----------|
| ① 状态 | `curMax / curMin` = 以当前元素结尾的最大/最小乘积 |
| ② 转移 | 见上;x < 0 时先交换 max/min 再转移 |
| ③ 初始化 | 都为 nums[0],ans = nums[0] |
| ④ 顺序 | 从左到右一遍扫 |
| ⑤ 优化 | 两个变量就是终极形态,O(1) 空间 |

### 10.2 与 LC53 的对比

| | LC53 最大子数组**和** | LC152 最大子数组**积** |
|---|---|---|
| 状态 | 以 i 结尾的最大和 | 以 i 结尾的最大**和最小**积 |
| 负数 | 只会拉低,直接舍弃 | 可能翻身,必须双状态 |
| 0 | 无特殊影响 | 归零,靠"和自身比较"自动另起炉灶 |

### 10.3 代码

```go
package main

import "fmt"

func maxProduct(nums []int) int {
	curMax, curMin, ans := nums[0], nums[0], nums[0]
	for i := 1; i < len(nums); i++ {
		x := nums[i]
		if x < 0 {
			curMax, curMin = curMin, curMax // 负数:大小身份互换
		}
		if x > curMax*x { // 要么另起炉灶,要么接前面
			curMax = x
		} else {
			curMax *= x
		}
		if x < curMin*x {
			curMin = x
		} else {
			curMin *= x
		}
		if curMax > ans {
			ans = curMax // 答案要一路取 max
		}
	}
	return ans
}

func main() {
	fmt.Println(maxProduct([]int{2, 3, -2, 4}) == 6) // 子数组 [2,3]
	fmt.Println(maxProduct([]int{-2, 0, -1}) == 0)   // 0 把负积截断
}
```

### 10.4 复杂度

| 维度 | 分析 |
|------|------|
| 时间 | O(n) |
| 空间 | O(1) |

### 10.5 易错点

- 交换 max/min 必须发生在转移**之前**,顺序反了结果全错
- curMax / curMin 每轮都要"和 x 自身比较"(另起炉灶),否则过不了含 0 的用例
- 答案不能只看最后的 curMax,要全程维护最大值

### 🎤 口述模板

> "乘积和求和的本质区别是负负得正,所以我在'以 i 结尾'的维度同时维护最大积和最小积:遇到负数先把两个身份交换再转移,遇到 0 靠和自身比较自动另起炉灶,一遍线性扫完,空间 O(1)。"

## 十一、LC416 分割等和子集(中等)

> 给你只含**正整数**的非空数组 nums,判断能否分割成两个子集,使两者的元素和相等。

### 11.1 解题思路

先做数学变形:设总和为 sum,能分成相等两半 ⟹ 每一半都是 sum/2。所以 sum 为奇数直接 false,问题变成:**能否选出若干个数,恰好凑出 sum/2?** 这就是标准的 **01 背包可行性**问题(每个数只能选一次)。

```
一维为什么必须倒序?(面试高频追问)
  倒序:j 从大到小 → 算 dp[j] 时读到的 dp[j-num] 还是上一轮旧值
        → nums[i] 至多被用一次 ✓ 这是 01 背包
  正序:j 从小到大 → dp[j-num] 已混入本轮 nums[i],同一个数反复选
        → 退化成完全背包 ✗
```

| 步骤 | 本题答案 |
|------|----------|
| ① 状态 | `dp[j]` = 能否选出子集,和恰好为 j |
| ② 转移 | `dp[j] = dp[j] \|\| dp[j-num]` |
| ③ 初始化 | `dp[0]=true`(什么都不选凑 0) |
| ④ 顺序 | 外层遍历数,内层容量**倒序** |

### 11.2 代码

```go
package main

import "fmt"

func canPartition(nums []int) bool {
	sum := 0
	for _, v := range nums {
		sum += v
	}
	if sum%2 != 0 {
		return false // 奇数和必然切不出两个相等整数
	}
	target := sum / 2
	dp := make([]bool, target+1)
	dp[0] = true // 凑 0:什么都不选
	for _, num := range nums {
		for j := target; j >= num; j-- { // 倒序!每个数只用一次
			if dp[j-num] {
				dp[j] = true
			}
		}
	}
	return dp[target]
}

func main() {
	fmt.Println(canPartition([]int{1, 5, 11, 5}) == true) // [1,5,5] 与 [11]
	fmt.Println(canPartition([]int{1, 2, 3, 5}) == false)
}
```

### 11.3 复杂度

| 维度 | 分析 |
|------|------|
| 时间 | O(n × target),target = sum/2 |
| 空间 | O(target) |

### 11.4 易错点

- 内层必须 `j >= num`,否则 `dp[j-num]` 负下标 panic
- 倒序忘了写就成了完全背包,[2,2,3,5] 这类用例会露馅

### 🎤 口述模板

> "转化成 01 背包:总和为奇数直接 false,否则看能否选数凑出 sum/2。dp[j] 表示和 j 是否可凑出,转移是或上 dp[j 减 num],初始化只有 dp[0] 为真。关键细节是容量倒序遍历,保证每个数只选一次,正序就退化成完全背包。"

## 十二、LC32 最长有效括号(困难)

> 给你只含 '(' 和 ')' 的字符串 s,找出最长的**格式正确且连续**的有效括号子串的长度。

### 12.1 解题思路

困难题,别慌,栈也能做(匹配时算长度),但 DP 解法更能体现"状态定义"的功力。有效括号串有个美妙性质:**一定以 ')' 结尾**——以 '(' 结尾的串,那个左括号永远配不上对。顺着性质定义:

```
dp[i] = 以 s[i] 结尾的最长有效括号子串的长度
```

于是 s[i]='(' 时 dp[i]=0,秒杀;重点推 s[i]=')' 的两种情况:

```
情况一 s[i-1]='(' 即 "…()" :
    … ( )          dp[i] = 2 + dp[i-2]
      i-1 i        (拼上前面紧邻的有效段)

情况二 s[i-1]=')' 即 "…))" :
    … ( ( ) ( ) )  中间 L = dp[i-1] 是有效段
      ↑ └── L ──┘↑ 和 s[i] 配对的 '(' 藏在 k = i-1-L
      k           i 若 s[k]=='(' : dp[i] = L + 2 + dp[k-1]
```

拿 `"(())"` 走一遍:dp 依次为 0、0、2、4(i=3 走情况二,k=0 恰是 '(')。初始化全 0、从左到右扫、答案取全局 max。

### 12.2 代码

```go
package main

import "fmt"

func longestValidParentheses(s string) int {
	n := len(s)
	dp := make([]int, n) // dp[i]:以 s[i] 结尾的最长有效长度
	ans := 0
	for i := 1; i < n; i++ {
		if s[i] == '(' {
			continue // '(' 结尾必无效,dp[i] 保持 0
		}
		if s[i-1] == '(' { // 情况一:"()"
			dp[i] = 2
			if i >= 2 {
				dp[i] += dp[i-2] // 拼上前面紧邻的有效段
			}
		} else if k := i - dp[i-1] - 1; k >= 0 && s[k] == '(' { // 情况二:"))"
			dp[i] = dp[i-1] + 2 // 跨过中间有效段,配对成功
			if k >= 1 {
				dp[i] += dp[k-1] // 配对的 '(' 前面可能还有有效段!
			}
		}
		if dp[i] > ans {
			ans = dp[i] // 答案取全局最大
		}
	}
	return ans
}

func main() {
	fmt.Println(longestValidParentheses("(()") == 2)
	fmt.Println(longestValidParentheses(")()())") == 4)
}
```

### 12.3 复杂度

| 维度 | 分析 |
|------|------|
| 时间 | O(n) |
| 空间 | O(n)(栈解法同样 O(n)) |

### 12.4 易错点

- 两个分支的"再拼一段"(dp[i-2] / dp[k-1])极易漏,漏了 `"()()"`、`"()(())"` 就错
- 情况二先算 k = i-dp[i-1]-1,必须同时判 k ≥ 0(防越界)和 s[k]=='('
- 答案是全局 max,不是 dp[n-1]

### 🎤 口述模板

> "我定义 dp[i] 为以 i 结尾的最长有效括号长度,因为有效串必以右括号结尾。s[i] 是右括号分两种:前一个是左括号,长度是 dp[i-2] 加 2;前一个也是右括号,就跳过中间 dp[i-1] 长的有效段去找配对的左括号,长度是 dp[i-1] 加 2,再拼上配对括号前面的有效段。全程维护最大值,线性时间。"

## 十三、收官

DP 的本质就一句话:**把大问题的答案,建在小问题的答案上**。爬楼梯是"最后一步从哪来",背包是"这个数选不选",乘积最大是"负数会不会翻身"——状态定义想清楚了,剩下的全是套路搬运。下一篇见!
