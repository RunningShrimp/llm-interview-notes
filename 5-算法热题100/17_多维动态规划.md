# 17 | 多维动态规划：状态扩展到二维（区间的 DP）

> LeetCode 热题 100 · 多维 DP 组全 5 题：LC62 / LC64 / LC5 / LC1143 / LC72
> 这组的公共套路：**状态定义从一维扩成二维**——网格坐标 `(i,j)` 是位置状态；起止区间 `[i,j]` 是区间状态。转移时往往要"看左上/左上左"邻居，**空间压缩从一行到 O(1) 是常考追问**。

## 本组题目总览

| # | LC 题号 | 题目 | 状态定义 | 难度 |
|---|---------|------|----------|------|
| 1 | 62  | 不同路径           | 网格坐标 `dp[i][j]` | 中等 |
| 2 | 64  | 最小路径和         | 网格坐标 `dp[i][j]` | 中等 |
| 3 | 5   | 最长回文子串       | 起止区间 `dp[i][j]` | 中等 |

| 5 | 72  | 编辑距离           | 双串前缀 `(i,j)`   | 困难 |

## 多维 DP 三件套（先立框架）

| 维度 | 状态是什么 | 转移看哪 | 空间压缩思路 |
|------|------------|----------|---------------|
| 网格坐标 | `dp[i][j]` 走到的属性 | 上方 + 左方 | 一维数组滚动（按行更新） |
| 起止区间 | `dp[i][j]` 子串属性 | 内部子区间 `dp[i+1][j-1]` | 倒着遍历天然保证小区间先算 |
| 双串前缀 | `dp[i][j]` 前缀配对属性 | `dp[i-1][j]` / `dp[i][j-1]` / `dp[i-1][j-1]` | 两行滚动；本题 1143/72 可继续压到 O(min(m,n)) |

## 一、LC62 不同路径（中等）

### 题干简述

m×n 网格从左上走到右下，只能**向右或向下**，问多少条不同路径。`m=3, n=7 → 28`。

### 解题思路：到达 = 从上下来 + 从右来

把每个格子的"到达方式数"作为状态：除了第一行只能从左边来、第一列只能从上面来，**其他格子都从上方和左方两个方向汇集**。

```
f[i][j] = f[i-1][j] + f[i][j-1]

初值: f[0][*] = 1  f[*][0] = 1
```

直觉上等价于"路径数 = 组合数 C(m+n-2, m-1)"——选哪几步往下走，但 DP 写法通用性更强（后续 64 题加权重后不能直接用组合）。

**空间压缩到 O(n)**：按行更新时 `dp[j]` 在更新之前还存着"上一行的 dp[j]"（即 f[i-1][j]），而当前位置要写的是 `f[i-1][j] + f[i][j-1]`，其中 `f[i][j-1]` 已经是这一行更新过的左侧值——一维滚动天然成立：

```
初始: dp = [1, 1, 1, ..., 1]   （第 0 行全是 1）
逐格 j=1..n-1: dp[j] += dp[j-1]
```

### 完整可编译代码

```go
package main

import "fmt"

func uniquePaths(m, n int) int {
	dp := make([]int, n)
	for i := range dp {
		dp[i] = 1
	}
	for i := 1; i < m; i++ {
		for j := 1; j < n; j++ {
			dp[j] += dp[j-1] // 上方 + 左方
		}
	}
	return dp[n-1]
}

func main() {
	fmt.Println(uniquePaths(3, 7) == 28)  // true
	fmt.Println(uniquePaths(1, 1) == 1)   // true
	fmt.Println(uniquePaths(3, 3) == 6)   // true
}
```

### 复杂度

| 项 | 复杂度 |
|----|--------|
| 时间 | O(mn) |
| 空间 | O(n)（一维压缩） |

### 易错点

1. `dp[j] += dp[j-1]` 的写法只在**外层按行、内层按列**时成立；倒过来写状态意义全错。
2. 进阶追问"格子有障碍"（LC63）只多一个 `if obstacleGrid[i][j] == 1: dp[j] = 0`，必须放在更新之前。
3. 组合公式 `C(m+n-2, m-1)` 是数学捷径，但空间 O(1) 只在 m+n 固定型面试题里答一次足够。

### 🎤 口述模板

> "到达格子的路径数 = 上方到达数 + 左方到达数，边界都是 1。空间压一维：外层按行、内层按列 `dp[j] += dp[j-1]`，因为旧的 dp[j] 是上一行的 dp[j]，新的 dp[j-1] 是这一行刚更新的左侧值。O(mn) 时间、O(n) 空间。"

## 二、LC64 最小路径和（中等）

### 题干简述

m×n 网格填数字，从左上到右下只能右/下，求路径**数字和最小**。

### 解题思路：和 62 同骨架，转移换成"取小"

状态转移从"求和"换成"取最小 + 当前格子权重"，其他完全一致：

```
f[i][j] = grid[i][j] + min(f[i-1][j], f[i][j-1])
初值: f[0][0] = grid[0][0]
      f[0][j] = f[0][j-1] + grid[0][j]      （第一行只能从左来）
      f[i][0] = f[i-1][0] + grid[i][0]      （第一列只能从上来）
```

同样可压到一维：每次只保留当前行 + 左上方刚算的值。

### 完整可编译代码

```go
package main

import "fmt"

func minPathSum(grid [][]int) int {
	if len(grid) == 0 {
		return 0
	}
	m, n := len(grid), len(grid[0])
	dp := make([]int, n)
	dp[0] = grid[0][0]
	for j := 1; j < n; j++ { // 第一行：从左到右累加
		dp[j] = dp[j-1] + grid[0][j]
	}
	for i := 1; i < m; i++ {
		dp[0] += grid[i][0]          // 第一列：从上到下累加
		for j := 1; j < n; j++ {
			dp[j] = grid[i][j] + min(dp[j], dp[j-1])
		}
	}
	return dp[n-1]
}

func min(a, b int) int { if a < b { return a }; return b }

func main() {
	fmt.Println(minPathSum([][]int{{1, 3, 1}, {1, 5, 1}, {4, 2, 1}}) == 7) // true
	fmt.Println(minPathSum([][]int{{1, 2, 3}, {4, 5, 6}}) == 12)         // true
}
```

### 复杂度

| 项 | 复杂度 |
|----|--------|
| 时间 | O(mn) |
| 空间 | O(n)（一维压缩） |

### 易错点

1. 第一行初始化要"按行累加"而不是直接 `dp[j] = grid[0][j]`——题目要求路径上**所有格子**都计入。
2. 网格为空的边界 `len(grid) == 0` 容易漏，单题测试会过、批量挂掉。
3. 64 题**不能像 62 题用组合公式**——因为格子有权重，必须 DP。

### 🎤 口述模板

> "最小路径和 = 当前格子 + min(从上来, 从左来)，边界初始化是首行首列的累加和。和 62 题同骨架，区别就是转移从加法换成 min + 权重。压一维：每行先把 dp[0] 加上 grid[i][0]，然后逐格 `dp[j] = grid[i][j] + min(dp[j], dp[j-1])`。O(mn) 时间、O(n) 空间。"

## 三、LC5 最长回文子串（中等）

### 题干简述

字符串 s 找**最长回文子串**。`"babad" → "bab"` 或 `"aba"`。要求 O(n²)。

### 解题思路：区间 DP——"i..j 是不是回文"由"i+1..j−1"递推

判断回文是天然的区间属性：`s[i..j]` 是否回文 = 两端字符相同 + 内部 `s[i+1..j−1]` 也回文。**长度 1 和 2 的子串需要特判**（内部区间为空时也成立）：

```
dp[i][j] = (s[i] == s[j]) && (j-i < 3 || dp[i+1][j-1])
         ├── j-i==0  单字符，回文 ✓
         ├── j-i==1  两字符相同，回文 ✓
         └── j-i>=2  端点同 + 内部也回文

遍历顺序: i 必须从大到小，j 从小到大——保证算 dp[i][j] 时 dp[i+1][j-1] 已存在
```

区间 DP 的关键：**状态是区间而非位置**，循环顺序要让"小区间先算出来"。倒序 `i` 从 n−1 降到 0，配合正序 `j` 从 i+1 到 n−1，自然满足。

返回最长回文需要**记录长度+起止**，遍历时不断更新最长那对 `(start, end)`。**空间 O(1) 的中心扩展法**也常见（每个中心向两侧扩）作为对照解。

### 完整可编译代码

```go
package main

import "fmt"

func longestPalindrome(s string) string {
	n := len(s)
	if n < 2 {
		return s
	}
	dp := make([][]bool, n)
	for i := range dp {
		dp[i] = make([]bool, n)
		dp[i][i] = true // 单字符必回文
	}
	start, maxLen := 0, 1
	// i 倒序、j 正序：保证 dp[i+1][j-1] 先算
	for i := n - 1; i >= 0; i-- {
		for j := i + 1; j < n; j++ {
			if s[i] == s[j] {
				if j-i < 3 || dp[i+1][j-1] {
					dp[i][j] = true
					if j-i+1 > maxLen {
						maxLen = j - i + 1
						start = i
					}
				}
			}
		}
	}
	return s[start : start+maxLen]
}

func main() {
	out := longestPalindrome("babad")
	fmt.Println(out == "bab" || out == "aba") // true
	fmt.Println(longestPalindrome("cbbd") == "bb")    // true
	fmt.Println(longestPalindrome("a") == "a")         // true
	fmt.Println(longestPalindrome("aaaa") == "aaaa")   // true
}
```

### 复杂度

| 项 | 复杂度 |
|----|--------|
| 时间 | O(n²) |
| 空间 | O(n²) dp（中心扩展版可省到 O(1)） |

### 易错点

1. **循环顺序**写反（i 正序、j 倒序）状态依赖就破，所有 dp[i+1][j-1] 都是零值 false，回文判不出来。
2. `dp[i][i] = true` 必先初始化，单字符回文是所有递推的地基。
3. 返回值要追踪 `(start, maxLen)` 而不是只比较长度——题要的是**子串本体**。

### 🎤 口述模板

> "区间 DP：`dp[i][j]` 表示 s[i..j] 是不是回文。转移是端点相同且内部 `dp[i+1][j-1]` 也是回文；长度 1、2 的子串内部为空时直接成立。关键是循环 i 倒序、j 正序，保证子区间先算。复杂度 O(n²) 时间和空间；要子串本体得沿途记 start 和 maxLen。中心扩展法空间 O(1) 是另一套路。"

## 四、LC1143 最长公共子序列（中等）

### 题干简述

两字符串 text1、text2 找**最长公共子序列**（LCS）长度。子序列不要求连续但保相对顺序。`"abcde" 与 "ace" → 3`。

### 解题思路：双串前缀 `(i,j)` 状态，最后一对字符四种解法

把双串切成前缀对：状态 `dp[i][j]` = `text1[0..i-1]` 与 `text2[0..j-1]` 的 LCS 长度（i/j 是前缀长度而非下标）。**最后一个字符配不配**是核心：

```
if text1[i-1] == text2[j-1]:
    dp[i][j] = dp[i-1][j-1] + 1      # 这一对字符选上，LCS 接长
else:
    dp[i][j] = max(dp[i-1][j], dp[i][j-1])  # 砍一头（两个方向都试，取大）

初值: dp[0][*] = 0  dp[*][0] = 0   （空串的 LCS 为 0）
```

二维表格看本质：

```
   ""  a  c  e
""   0  0  0  0
a    0  1  1  1
b    0  1  1  1
c    0  1  2  2
e    0  1  2  3   ← dp[5][4]=3 ✓
```

**空间压缩**到 O(min(m,n))：按行更新时只保留上一行的 `dp[j]` 和本行的 `dp[j-1]`，用一个变量 `prev` 暂存左上角即可——和 62/64 一样的滚动套路。

### 完整可编译代码

```go
package main

import "fmt"

func longestCommonSubsequence(text1, text2 string) int {
	m, n := len(text1), len(text2)
	if m < n { // 在短串上开数组
		text1, text2 = text2, text1
		m, n = n, m
	}
	dp := make([]int, n+1) // n+1：含 j=0 的 0 列
	for i := 1; i <= m; i++ {
		prev := 0 // dp[i-1][j-1] 的备份（左上角）
		for j := 1; j <= n; j++ {
			tmp := dp[j] // 旧 dp[j] = dp[i-1][j]，下一轮要当左上角用
			if text1[i-1] == text2[j-1] {
				dp[j] = prev + 1
			} else if dp[j] > dp[j-1] {
				// dp[j] 还是旧值（dp[i-1][j]），dp[j-1] 是本行新值
				// 啥也不做，dp[j] 已是更大的那个
			} else {
				dp[j] = dp[j-1]
			}
			prev = tmp
		}
	}
	return dp[n]
}

func main() {
	fmt.Println(longestCommonSubsequence("abcde", "ace") == 3)   // true
	fmt.Println(longestCommonSubsequence("abc", "abc") == 3)     // true
	fmt.Println(longestCommonSubsequence("abc", "def") == 0)     // true
}
```

### 复杂度

| 项 | 复杂度 |
|----|--------|
| 时间 | O(mn) |
| 空间 | O(min(m,n))（短串滚动） |

### 易错点

1. `dp` 维度 `n+1`：第第 0 行/列是空串前缀，全为 0——不预留这一圈递推要出界。
2. 压缩版的关键变量 `prev` 是左上角（`dp[i-1][j-1]`），赋值要在**旧 dp[j] 读出之后**再用，不然被覆盖算错。
3. 进阶追问"输出 LCS 本体"要再加反向追踪：回看 dp 数组沿转移方向往回走，遇到相等的字符就收集——空间换功能。

### 🎤 口述模板

> "LCS 是双串前缀 DP。状态 `dp[i][j]` 是两串前缀的 LCS 长度。转移看最后一对字符：相等就左上角+1，不等就上方和左方取大。空串初始化为 0。压缩到短串长度的滚动数组，关键是用 `prev` 备份左上角，因为更新 dp[j] 时旧 dp[j]（上方值）马上要被覆盖——而下一格的左上角需要它。"

## 五、LC72 编辑距离（困难）

### 题干简述

word1 变 word2 至少需要多少步操作（**增/删/替**），每步代价 1。`"horse" → "ros" → 3`。

### 解题思路：LCS 升级版——把"不等"拆成三种操作

把 LCS 里"max(上, 左)" 进一步细化为三种操作：

```
if word1[i-1] == word2[j-1]:
    dp[i][j] = dp[i-1][j-1]                # 字符配对，不用操作
else:
    # 三种操作都使长度对齐，取代价最小的那个
    删: dp[i-1][j]   + 1    # 删 word1[i-1]（上方向）
    增: dp[i][j-1]   + 1    # 增一个 word2[j-1]（左方向）
    替: dp[i-1][j-1] + 1    # 替 word1[i-1] 为 word2[j-1]（左上方向）
    dp[i][j] = min(三者)
```

为什么三种操作各自 +1 就够？——把"操作后两前缀对齐"统一抽象：**删 word1[i-1] 后变成 word1[0..i-2] 对 word2[0..j-1]**；**在 word1 增一个 word2[j-1]**（或者等价地从 word2 删）；**替换则两端都前移一步**。三种都能把 (i,j) 退到更小的子问题。

```
   ""  r  o  s
""   0  1  2  3
h    1  1  2  3
o    2  2  1  2
r    3  2  2  2
s    4  3  3  2   ← dp[5][3]=3 ✓ horse→ros
e    5  4  4  3
```

### 完整可编译代码

```go
package main

import "fmt"

func minDistance(word1, word2 string) int {
	m, n := len(word1), len(word2)
	dp := make([][]int, m+1)
	for i := range dp {
		dp[i] = make([]int, n+1)
		dp[i][0] = i // 删 i 次到空串
	}
	for j := 0; j <= n; j++ {
		dp[0][j] = j // 增 j 次得到 word2 前缀
	}
	for i := 1; i <= m; i++ {
		for j := 1; j <= n; j++ {
			if word1[i-1] == word2[j-1] {
				dp[i][j] = dp[i-1][j-1]
			} else {
				dp[i][j] = min3(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1
			}
		}
	}
	return dp[m][n]
}

func min3(a, b, c int) int {
	m := a
	if b < m {
		m = b
	}
	if c < m {
		m = c
	}
	return m
}

func main() {
	fmt.Println(minDistance("horse", "ros") == 3)  // true
	fmt.Println(minDistance("intention", "execution") == 5) // true
	fmt.Println(minDistance("", "a") == 1)          // true
}
```

### 复杂度

| 项 | 复杂度 |
|----|--------|
| 时间 | O(mn) |
| 空间 | O(mn)（可压到 O(min(m,n))，问到位就动手） |

### 易错点

1. 初始化边界 `dp[i][0] = i`（删 i 次）和 `dp[0][j] = j`（增 j 次），不写则整张表错位。
3. 三种操作只是**对齐到子问题的方式**，没有重复计步——新增的 +1 是当前步的代价，别写两遍。
3. 进阶追问"操作代价不同"（如替换 2）只把 `+1` 改成对应 cost，公式不变。

### 🎤 口述模板

> "编辑距离是双串前缀 DP 的加强版。状态 `dp[i][j]` 是 word1 前 i、word2 前 j 的编辑距离。相等时退一格 `dp[i-1][j-1]`；不等时把'不等'拆成三种对齐方式——删一个（上方向+1）、增一个（左方向+1）、替一个（左上方向+1），取最小再 +1。边界是单边到空串的次数。O(mn) 时间空间，可压到短串。"

## 收尾：多维 DP 组一张表

| 题 | 状态类型 | 状态含义 | 转移看哪 | 压缩极限 |
|----|----------|----------|----------|----------|
| LC62 | 网格坐标 | 路径数 | 上 + 左 | O(n) |
| LC64 | 网格坐标 | 最小路径和 | min(上, 左) + 自身 | O(n) |
| LC5  | 起止区间 | 是否回文 | 内部区间 `dp[i+1][j-1]` | 中心扩展 O(1) |
| LC1143 | 双串前缀 | LCS 长度 | 左上/上/左 | O(min(m,n)) |
| LC72 | 双串前缀 | 编辑距离 | 左上/上/左（含三种操作） | O(min(m,n)) |

多维 DP 的通用面试心法：**先一句话说清状态是什么（坐标 / 区间 / 双串前缀）、转移看哪几个邻居**，再开写。状态维度从 1 到 2 时，最大的坑不是转移而是**循环顺序**——必须保证依赖的子状态先算出来（区间 DP i 倒序、双串 DP i 正序 j 正序）。压缩是后续追问锦上添花，先把二维写对再考虑降维。
