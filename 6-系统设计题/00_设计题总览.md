## 考频校准说明（2026-08）

选题不是凭感觉，是按 2025-2026 真实面试情报校准的：

- **RAG 全链路 + 延迟成本优化**：多来源独立验证的最高频设计题方向（题 9）。
- **Agent 模块拆解 / 多 Agent 协作 / Agent 记忆系统 / MCP 治理**：2026 年增量最快的方向（题 7、8）。
- **多模型动态路由与故障兜底 / LLM API 超时异常 / Token 成本排查**：一手验证高频（题 6、11、13）。
- **评测（RAGAS / NDCG / Agent 评估）与 Run Trace 可观测**：平台岗位稳定考点（题 12、13）。
- **后端经典五题**：仍是场景题双雄 + 衍生追问池，2026 趋势是「穿插化 + 深度化」，且 AI 变体（多维限流 RPM/TPM、语义缓存、智能客服降级）已进入主流题库——题 4 专门埋了这条线。
- **A2A 协议**：检索未发现被直接考到，不入题（在 L9 热点区有概念储备即可）。

## 六步法速览（详细版见 L9）

```text
① 需求澄清 ─── 主动问 3-4 个问题（规模/读写比/一致性要求/延迟预算）
② 架构图   ─── 白板能画的 ASCII：数据流向 + 核心组件
③ 决策表   ─── 2-3 个关键点 × 多方案对比（优缺点 + 什么时候选）
④ 容量估算 ─── 整数近似口算：QPS / 存储 / 内存 / 成本
⑤ 追问链   ─── 每层都准备「为什么、什么时候不这么做、代价是什么」
⑥ 口述模板 ─── 250-350 字连贯口语稿，开背
```

## 刷题顺序建议

1. **第 1 周**：后端五题（题 1-5）——热身 + 找回白板手感，重点练「瓶颈定位 → 取舍分析」的表述。
2. **第 2 周**：RAG 三题（题 9-11）——AI 应用岗面试第一高频区，题 9 的全链路框架要能脱稿讲。
3. **第 3 周**：平台三题（题 6-8）——冲高级岗/平台岗的区分度所在，多 Agent 协作（题 8）是 2026 增量考点。
4. **第 4 周**：质量两题（题 12-13）+ 回炉 L9 入门四题——质量侧是后端转 AI 的优势区，用「测试/监控老经验翻译」的视角答。

每题练法：先自己按六步法答一遍（限时 25 分钟）→ 再对照参考答案找差距 → 最后背 🎤 口述模板 + 把追问链过三遍。
